### Dạng 1. Xác định tâm – bán kính – nhận biết phương trình mặt cầu

LOẠI 1LOẠI 2Phương Trình $\left ( { x-a } \right.  ) ^ { 2 } +\left ( { y-b } \right.  ) ^ { 2 } +\left ( { z-c } \right.  ) ^ { 2 } =R ^ { 2 }$ $x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2ax-2by-2cz+d=0$ Nhận xét⑴ Hệ số trước $x,y,z$ bằng nhau và bằng 1.⑵ Hệ số trước các ngoặc bằng nhau và bằng 1.⑶ Vế phải là hằng số dương.⑴ Hệ số trước $x ^ { 2 } ,y ^ { 2 } ,z ^ { 2 }$ bằng nhau và bằng 1.⑵ Phương trình đầy đủ $x ^ { 2 } ,y ^ { 2 } ,z ^ { 2 }$⑶ Thỏa mãn điều kiện tồn tại $a ^ { 2 } +b ^ { 2 } +c ^ { 2 } -d>0$ Xác ĐịnhTâmLấy hệ số tự do trong ngoặc $÷-1$. Lấy hệ số trước $x\,;\,y\,;\,z$ $÷-2$. Bán KínhLấy căn bậc 2 vế phải.$R=\sqrt{ a ^ { 2 } +b ^ { 2 } +c ^ { 2 } -d }$. Điều kiện tồn tại:$a ^ { 2 } +b ^ { 2 } +c ^ { 2 } -d>0$. Định nghĩa $S\left ( { I;\,R } \right.  )=\left\{ \begin{array}{l} M\|IM=R>0 \end{array} \right\}$. Cho hai điểm $A,\,B$ cố định. Nếu $MA⊥MB$ thì tập hợp điểm $M$ là mặt cầu $\left ( { S } \right.  )$ có tâm $I$ là trung điểm $AB$ và bán kính $R=\frac { AB } { 2 }$ Phương pháp

**Ví dụ 1.1.** Trong không gian $Oxyz$,xác định tọa độ tâm và bán kính các mặt cầu sau:⑴$\left ( { S } \right.  ):x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+4y-6z-2=0.$⑵$\left ( { S } \right.  ):\left ( { x-1 } \right.  ) ^ { 2 } +\left ( { y+2 } \right.  ) ^ { 2 } +z ^ { 2 } =9$

*Lời giải:*

⑴$\left ( { S } \right.  ):x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+4y-6z-2=0.$

Mặt cầu $\left ( { S } \right.  ):x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+4y-6z-2=0$ là $I\left ( { 1;-2;3 } \right.  )$ và $R=\sqrt{ 1 ^ { 2 } +\left ( { -2 } \right.  ) ^ { 2 } +3 ^ { 2 } -\left ( { -2 } \right.  ) }=4$

⑵$\left ( { S } \right.  ):\left ( { x-1 } \right.  ) ^ { 2 } +\left ( { y+2 } \right.  ) ^ { 2 } +z ^ { 2 } =9$

Mặt cầu $\left ( { S } \right.  ):\left ( { x-1 } \right.  ) ^ { 2 } +\left ( { y+2 } \right.  ) ^ { 2 } +z ^ { 2 } =9$ có tọa độ tâm $I\left ( { 1\,;\,-2\,;\,0 } \right.  )$ và $R=3$.

**Ví dụ 1.2.** Trong không gian $Oxyz$,cho các phương trình sau:⑴$2x ^ { 2 } +2y ^ { 2 } =\left ( { x+y } \right.  ) ^ { 2 } -z ^ { 2 } +2xxy$⑵$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+2y=0$⑶$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } +2x-2y+1=0$⑷$\left ( { x+y } \right.  ) ^ { 2 } =2xy-z ^ { 2 } +1-4x$ Có bao nhiêu phương trình mặt cầu và mặt cầu đấy nhận $I\left ( { -1\,;\,1\,;\,0 } \right.  )$ làm tâm?

*Lời giải:*

⑴$2x ^ { 2 } +2y ^ { 2 } =\left ( { x+y } \right.  ) ^ { 2 } -z ^ { 2 } +2xxy$

$2x ^ { 2 } +2y ^ { 2 } =\left ( { x+y } \right.  ) ^ { 2 } -z ^ { 2 } +2xxy$ $⇔2x ^ { 2 } +2y ^ { 2 } =x ^ { 2 } +y ^ { 2 } +2xy-z ^ { 2 } +2xxy$

$⇔x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+1=0⇔\left ( { x-1 } \right.  ) ^ { 2 } +y ^ { 2 } +z ^ { 2 } =0$ không là phương trình mặt cầu.

⑵$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+2y=0$

$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x+2y=0$

Kiểm tra:$1 ^ { 2 } +\left ( { -1 } \right.  ) ^ { 2 } =2>0$ là phương trình mặt cầu, có tâm $I\left ( { 1\,;\,-1\,;\,0 } \right.  )$.

⑶$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } +2x-2y+1=0$

$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } +2x-2y+1=0$.

Kiểm tra:$\left ( { -1 } \right.  ) ^ { 2 } +1 ^ { 2 } -1=1>0$ là phương trình mặt cầu, có tâm $I\left ( { -1\,;\,1\,;\,0 } \right.  )$.

⑷$\left ( { x+y } \right.  ) ^ { 2 } =2xy-z ^ { 2 } +1-4x$

$\left ( { x+y } \right.  ) ^ { 2 } =2xy-z ^ { 2 } +1-4x$ $⇔x ^ { 2 } +2xy+y ^ { 2 } -2xy+z ^ { 2 } -1+4x=0⇔x ^ { 2 } +y ^ { 2 } +z ^ { 2 } +4x-1=0$

Kiểm tra:$\left ( { -2 } \right.  ) ^ { 2 } -\left ( { -1 } \right.  )=5>0$ là phương trình mặt cầu, có tâm $I\left ( { -2\,;\,0\,;\,0 } \right.  )$.

Vậy, phương trình là phương trình mặt cầu và nhận

**Ví dụ 1.3.** Trong không gian $Oxyz$,cho các phương trình sau:⑴$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x=0$⑵$x ^ { 2 } +y ^ { 2 } -z ^ { 2 } +2x-y+1=0$⑶$2x ^ { 2 } +2y ^ { 2 } =\left ( { x+y } \right.  ) ^ { 2 } -z ^ { 2 } +2x-1$⑷$\left ( { x+y } \right.  ) ^ { 2 } =2xy-z ^ { 2 } -1$ Có bao nhiêu phương trình mặt cầu?

*Lời giải:*

⑴$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x=0$

$x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2x=0$ có tâm $I\left ( { 1\,;\,0\,;\,0 } \right.  )$ và $R=\sqrt{ 1 ^ { 2 } +0 ^ { 2 } +0 ^ { 2 } }=1$ là phương trình mặt cầu.

⑵$x ^ { 2 } +y ^ { 2 } -z ^ { 2 } +2x-y+1=0$

$x ^ { 2 } +y ^ { 2 } -z ^ { 2 } +2x-y+1=0$ không là phương trình mặt cầu vì hệ số trước $z ^ { 2 }$ khác hệ số trước $x ^ { 2 }$ và $y ^ { 2 }$.

⑶$2x ^ { 2 } +2y ^ { 2 } =\left ( { x+y } \right.  ) ^ { 2 } -z ^ { 2 } +2x-1$

$2x ^ { 2 } +2y ^ { 2 } =\left ( { x+y } \right.  ) ^ { 2 } -z ^ { 2 } +2x-1$ $⇔2x ^ { 2 } +2y ^ { 2 } =x ^ { 2 } +y ^ { 2 } +2xy-z ^ { 2 } +2x-1$

$⇔x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -2xy-2x+1=0$ không là phương trình mặt cầu.

⑷$\left ( { x+y } \right.  ) ^ { 2 } =2xy-z ^ { 2 } -1$

$\left ( { x+y } \right.  ) ^ { 2 } =2xy-z ^ { 2 } -1$ $⇔x ^ { 2 } +y ^ { 2 } +2xy=2xy-z ^ { 2 } -1$

$⇔x ^ { 2 } +y ^ { 2 } +z ^ { 2 } +1=0$ không là phương trình mặt cầu vì $x ^ { 2 } +y ^ { 2 } +z ^ { 2 } +1>0\,∀x\,;\,y\,;\,z$.

**Ví dụ 1.4.** Trong không gian $Oxyz$, cho hai điểm $A\left ( { 0;\,0;\,-1 } \right.  )$ và $B\left ( { 0;\,6;\,0 } \right.  )$. Chứng minh rằng nếu điểm $M\left ( { x;\,y;\,z } \right.  )$ thỏa mãn $\left. \overrightarrow { MA }.\,\overrightarrow { MB }=0 \right.$ thì $M$ thuộc một mặt cầu $\left ( { S } \right.  )$. Tìm tâm và bán kính của mặt cầu $\left ( { S } \right.  )$.

*Lời giải:*

Ta có $\overrightarrow { MA }=\left ( { -x;\,-y;\,-1-z } \right.  )$ và $\overrightarrow { MB }=\left ( { -x;\,6-y;\,-z } \right.  )$.

$\left. \overrightarrow { MA }.\,\overrightarrow { MB }=0⇔\,x ^ { 2 } -6y+y ^ { 2 } +z+z ^ { 2 } =0⇔\,x ^ { 2 } +y ^ { 2 } +z ^ { 2 } -6y+z=0 \right.$.

Khi đó theo dạng mặt cầu thì ta có:$a=0,\,b=3,\,c=-\frac { 1 } { 2 }$ và $d=0$.

Xét $a ^ { 2 } +b ^ { 2 } +c ^ { 2 } -d=\frac { 37 } { 4 }>0$.

Vậy tập hợp điểm $M$ là mặt cầu có tâm $I\left ( { 0;\,3;\,-\frac { 1 } { 2 } } \right.  )$, bán kính $R=\sqrt{ a ^ { 2 } +b ^ { 2 } +c ^ { 2 } -d }=\frac { \sqrt{ 37 } } { 2 }$.

**Ví dụ 1.5.** Trong không gian $Oxyz$, cho hai điểm $A\left ( { -2;2;-2 } \right.  )$;$B\left ( { 3;-3;3 } \right.  )$. Điểm $M$ trong không gian thỏa mãn $\frac { MA } { MB }=\frac { 2 } { 3 }$. Tính độ dài $OM$ lớn nhất.

Như vậy, điểm $M$ thuộc mặt cầu $\left ( { S } \right.  )$ tâm $I\left ( { -6;6;-6 } \right.  )$ và bán kính $R=\sqrt{ 108 }=6\sqrt{ 3 }$.

Mặt cầu $\left ( { S } \right.  )$ có phương trình:$\left ( { S } \right.  ):\left ( { x-32 } \right.  ) ^ { 2 } +\left ( { y-50 } \right.  ) ^ { 2 } +\left ( { z-8 } \right.  ) ^ { 2 } =100$ nên có tâm $I\left ( { 32;50;8 } \right.  )$ và bán kính $R=\sqrt{ 100 }=10$.

⑵ Tìm tọa độ hình chiếu vuông góc $J$ của tâm $I$ trên mặt sân.

Trong không gian $Oxyz$, mặt sân có phương trình $z=0$ trùng với mặt phẳng tọa độ $\left ( { Oxy } \right.  )$, suy ra hình chiếu vuông góc của điểm $I\left ( { 32;50;8 } \right.  )$ xuống mặt sân có tọa độ $J\left ( { 32;50;0 } \right.  )$.

⑶ Tính khoảng cách từ vị trí $M$ của quả bóng đến điểm $J$.

Trong tam giác vuông $IJM$, ta có:$\overrightarrow { JI }=\left ( { 0;0;8 } \right.  )⇒IJ=8,\,\,IM=R=10$.

Suy ra:$JM=\sqrt{ IM ^ { 2 } -JI ^ { 2 } }=\sqrt{ 10 ^ { 2 } -8 ^ { 2 } }=6$.

Vậy khoảng cách từ vị trí $M$ của quả bóng đến điểm $J$ là $6\,m$.
