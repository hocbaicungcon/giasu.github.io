# Bài tập Toán 12: Phương trình đường thẳng trong không gian $Oxyz$

> **Tóm tắt chuyên đề:** Phương trình chính tắc và tham số của đường thẳng, vị trí tương đối giữa hai đường thẳng, khoảng cách và góc trong không gian $Oxyz$ Toán 12 có bài tập và đáp án chi tiết.

## I. Lý thuyết trọng tâm cần nhớ

### 1. Phương trình đường thẳng

Vectơ chỉ phương của đường thẳng:Cho đường thẳng $\Delta $ và vectơ $u$ khác $\overrightarrow { 0 }$. Vectơ $u$ được gọi là vectơ chỉ phương của đường thẳng $\Delta $ nếu giá của $u$ song song hoặc trùng với $\Delta $.

 Nhận xét:

- Một đường thẳng hoàn toàn được xác định khi biết một điểm mà nó đi qua và một vectơ chỉ phương của nó.

- Nếu $u$ là một vectơ chỉ phương của đường thẳng thì $k.u{ \rm{ } }\left ( { k≠0 } \right.  )$ cũng là một vectơ chỉ phương của đường thẳng đó.

Phương trình tham số của đường thẳng:Trong không gian $Oxyz$, phương trình tham số của đường thẳng $\Delta $ qua điểm $M\left ( { x_{ 0 } ;y_{ 0 } ;z_{ 0 } } \right.  )$ và nhận $u=\left ( { a;b;c } \right.  )$ làm vectơ chỉ phương có dạng:$\left\{ \begin{array}{l} x=x_{ 0 } +aty=y_{ 0 } +btz=z_{ 0 } +ct \end{array} \right.$ với $t∈\mathbb{R}$ ($t$ được gọi là tham số và $a ^ { 2 } +b ^ { 2 } +c ^ { 2 } ≠0$)

Phương trình chính tắc của đường thẳng:Trong không gian $Oxyz$, phương trình chính tắc của đường thẳng $\Delta $ qua điểm $M\left ( { x_{ 0 } ;y_{ 0 } ;z_{ 0 } } \right.  )$ và nhận $u=\left ( { a;b;c } \right.  )$ làm vectơ chỉ phương có dạng:$\frac { x-x_{ 0 } } { a }=\frac { y-y_{ 0 } } { b }=\frac { z-z_{ 0 } } { c }$ ($a.b.c≠0$)

Phương trình đường thẳng qua hai điểm cho trước:Trong không gian $Oxyz$, cho đường thẳng $\Delta $ đi qua hai điểm $A\left ( { x_{ A } ;y_{ A } ;z_{ A } } \right.  ),B\left ( { x_{ B } ;y_{ B } ;z_{ B } } \right.  )$ và nhận $\overrightarrow { AB }=\left ( { x_{ B } -x_{ A } ;y_{ B } -y_{ A } ;z_{ B } -z_{ A } } \right.  )$ làm vectơ chỉ phương có: Phương trình tham số :$\left\{ \begin{array}{l} x=x_{ A } +\left ( { x_{ B } -x_{ A } } \right.  )ty=y_{ A } +\left ( { y_{ B } -y_{ A } } \right.  )tz=z_{ A } +\left ( { z_{ B } -z_{ A } } \right.  )t \end{array} \right.$ với $t∈\mathbb{R}$ Phương trình chính tắc:$\frac { x-x_{ A } } { x_{ B } -x_{ A } }=\frac { y-y_{ A } } { y_{ B } -y_{ A } }=\frac { z-z_{ A } } { z_{ B } -z_{ A } }$ (với $x_{ B } ≠x_{ A } ,y_{ B } ≠y_{ A } ,z_{ B } ≠z_{ A }$)

### 2. Vị trí tương đối hai đường thẳng. Điều kiện để hai đường thẳng vuông góc

Sự cùng phương – Sự đồng phẳng:Trong không gian $Oxyz$,
- Hai vectơ được gọi là cùng phương khi giá của chúng cùng song song với một đường thẳng.

- Ba vectơ được gọi là đồng phẳng khi giá của chúng cùng song song với một mặt phẳng. Trong không gian $Oxyz$, cho ba vecto $\left. a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  ),\overrightarrow { b }=\left ( { b_{ 1 } ;b_{ 2 } ;b_{ 3 } } \right.  ) \right.$ và $c=\left ( { c_{ 1 } ;c_{ 2 } ;c_{ 3 } } \right.  )$ Hai $a,\,\,b$ cùng phương $\left. ⇔\left[ a,\,\,b \right]=\overrightarrow { 0 } \right.$. Hai $a,\,\,b$ không cùng phương $\left. ⇔\left[ a,\,\,b \right]≠\overrightarrow { 0 } \right.$. Ba vectơ $a,\,\,b,\,\,c$ đồng phẳng $⇔\left[ a,\,\,b \right].\,c=0$. Ba vectơ $a,\,\,b,\,\,c$ không đồng phẳng $⇔\left[ a,\,\,b \right].\,c≠0$.

Vị trí tương đối giữa hai đường thẳng:

Trong không gian $Oxyz$, cho hai đường thẳng $\Delta_1, \Delta_2$ lần lượt đi qua các điểm $M_1(x_1; y_1; z_1), M_2(x_2; y_2; z_2)$ và có các vectơ chỉ phương $\vec{u_1} = (a_1; b_1; c_1), \vec{u_2} = (a_2; b_2; c_2)$.

**Phương pháp vectơ:**
- **$\Delta_1 \parallel \Delta_2$:** $[\vec{u_1}, \vec{u_2}] = \vec{0}$ và $[\vec{u_1}, \vec{M_1M_2}] \ne \vec{0}$ (hai VTCP cùng phương và $M_1 \notin \Delta_2$).
- **$\Delta_1 \equiv \Delta_2$:** $[\vec{u_1}, \vec{u_2}] = \vec{0}$ và $[\vec{u_1}, \vec{M_1M_2}] = \vec{0}$ (hai VTCP cùng phương và $M_1 \in \Delta_2$).
- **$\Delta_1$ cắt $\Delta_2$:** $[\vec{u_1}, \vec{u_2}] \ne \vec{0}$ và $[\vec{u_1}, \vec{u_2}] \cdot \vec{M_1M_2} = 0$ (hai VTCP không cùng phương và 3 vectơ đồng phẳng).
- **$\Delta_1, \Delta_2$ chéo nhau:** $[\vec{u_1}, \vec{u_2}] \cdot \vec{M_1M_2} \ne 0$ (ba vectơ không đồng phẳng).

**Phương pháp xét hệ phương trình:**
Từ phương trình tham số của $\Delta_1$ (tham số $t_1$) và $\Delta_2$ (tham số $t_2$), xét hệ phương trình hai ẩn $t_1, t_2$:
$$\begin{cases} x_1 + a_1 t_1 = x_2 + a_2 t_2 \\ y_1 + b_1 t_1 = y_2 + b_2 t_2 \\ z_1 + c_1 t_1 = z_2 + c_2 t_2 \end{cases} \quad (*)$$
- **$\Delta_1 \parallel \Delta_2$:** $\vec{u_1}, \vec{u_2}$ cùng phương và hệ $(*)$ vô nghiệm.
- **$\Delta_1 \equiv \Delta_2$:** Hệ $(*)$ có vô số nghiệm.
- **$\Delta_1$ cắt $\Delta_2$:** Hệ $(*)$ có nghiệm duy nhất $(t_1; t_2)$.
- **$\Delta_1$ và $\Delta_2$ chéo nhau:** $\vec{u_1}, \vec{u_2}$ không cùng phương và hệ $(*)$ vô nghiệm.

Điều kiện để hai đường thẳng vuông góc:Trong không gian $Oxyz$, cho hai đường thẳng $\Delta _{ 1 } ,\Delta _{ 2 }$ tương ứng có $u_{ 1 } =\left ( { a_{ 1 } ;b_{ 1 } ;c_{ 1 } } \right.  )$ và $u_{ 2 } =\left ( { a_{ 2 } ;b_{ 2 } ;c_{ 2 } } \right.  )$ là hai vectơ chỉ phương. Khi đó, ta có:$\Delta _{ 1 } ⊥\Delta _{ 2 } ⇔u_{ 1 } ⊥u_{ 2 } ⇔u_{ 1 } .u_{ 2 } =0⇔a_{ 1 } a_{ 2 } +b_{ 1 } b_{ 2 } +c_{ 1 } c_{ 2 } =0$

**Câu 15:** Trạm tàu cứu hộ được đặt tại vị trí $A(5; 0; 0)$ trên một hòn đảo nhỏ trong không gian $Oxyz$ (đơn vị trên mỗi trục được tính bằng km), được sử dụng làm trạm cứu hộ, cứu nạn trên biển. Tàu du lịch $B$ đang di chuyển (vận tốc không đổi) trên tuyến đường được mô tả bởi đường thẳng $d_1: \left\{ \begin{array}{l} x=2+t \\ y=1-2t \\ z=0 \end{array} \right.$. Tàu chở hàng $C$ đang di chuyển (vận tốc không đổi) trên tuyến đường vận tải được mô tả bởi đường thẳng $d_2: \left\{ \begin{array}{l} x=2-s \\ y=11+s \\ z=0 \end{array} \right.$. Do thời tiết xấu, nên hai tàu $B$ và $C$ gặp sự cố và cần được tiếp cận khẩn cấp. Trạm cứu hộ điều một tàu cứu hộ xuất phát từ $A$ để lần lượt tiếp cận tàu du lịch $B$ trước, sau đó đến tàu chở hàng $C$. Xét vị trí tối ưu của tàu du lịch $B$ dừng lại và tàu chở hàng $C$ dừng lại sao cho tổng quãng đường tàu cứu hộ cần đi $T=AB+BC+CA$ là nhỏ nhất. Khi đó $P_{\min} = \sqrt{a}\text{ (km)}$, hãy tính $a+2025$?

<details>
<summary><b>Xem đáp số & lời giải chi tiết: 2269</b></summary>

> **Đáp số:** `2269`

Chúng ta cần tìm vị trí tối ưu của tàu du lịch $B$ và tàu chở hàng $C$ sao cho tổng quãng đường cứu hộ $T = AB + BC + CA$ là nhỏ nhất.

Trong không gian $Oxyz$, ta có:
Hai đường thẳng $d_1, d_2$ cùng nằm trong mặt phẳng $(\alpha): z=0$ và $A \in (\alpha)$.
$d_1$ có một vectơ chỉ phương $\vec{u}_1 = (1; -2; 0)$; $d_2$ có một vectơ chỉ phương $\vec{u}_2 = (-1; 1; 0)$. Do $[\vec{u}_1, \vec{u}_2] \ne \vec{0}$ nên $d_1$ cắt $d_2$.

Gọi $A_1, A_2$ lần lượt là điểm đối xứng của $A$ qua $d_1$ và $d_2$.
- Gọi $(P)$ là mặt phẳng qua $A$ và vuông góc với $d_1 \Rightarrow (P): x - 2y - 5 = 0$.
Gọi $I = (P) \cap d_1$, tọa độ điểm $I$ là nghiệm của hệ:
$\left\{ \begin{array}{l} x = 2 + t \\ y = 1 - 2t \\ z = 0 \\ x - 2y - 5 = 0 \end{array} \right. \Rightarrow I(3; -1; 0) \Rightarrow A_1(1; -2; 0)$.

- Gọi $(Q)$ là mặt phẳng qua $A$ và vuông góc với $d_2 \Rightarrow (Q): -x + y + 5 = 0$.
Gọi $J = (Q) \cap d_2$, tọa độ điểm $J$ là nghiệm của hệ:
$\left\{ \begin{array}{l} x = 2 - s \\ y = 11 + s \\ z = 0 \\ -x + y + 5 = 0 \end{array} \right. \Rightarrow J(9; 4; 0) \Rightarrow A_2(13; 8; 0)$.

Khi đó:
$T = AB + BC + CA = A_1B + BC + CA_2 \ge A_1A_2$.
Do đó, $T$ đạt giá trị nhỏ nhất khi $T = A_1A_2 \Rightarrow P_{\min} = A_1A_2 = \sqrt{(13-1)^2 + (8+2)^2 + 0} = \sqrt{244}\text{ (km)}$.
Suy ra $a = 244 \Rightarrow a + 2025 = 244 + 2025 = 2269$.

(Dấu bằng xảy ra khi $B, C, A_1, A_2$ thẳng hàng).

</details>
