<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

**Câu 6:** Trong không gian $Oxyz$, cho ba điểm $A\left ( { 1;2;-1 } \right.  ),B\left ( { 2;-1;3 } \right.  ),C\left ( { -4;7;5 } \right.  )$. Tọa độ chân đường phân giác trong góc $B$ của tam giác $ABC$ là $\left ( { a;b;c } \right.  )$. Tổng $T=a+b+c$.

<details>
<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

Ta có $BA=\sqrt{ \left ( { -1 } \right.  ) ^ { 2 } +3 ^ { 2 } +\left ( { -4 } \right.  ) ^ { 2 } }=\sqrt{ 26 }$,$BC=\sqrt{ 6 ^ { 2 } +\left ( { -8 } \right.  ) ^ { 2 } +\left ( { -2 } \right.  ) ^ { 2 } }=2\sqrt{ 26 }.$ Gọi $D\left ( { a;b;c } \right.  )$ là chân đường vuông góc trong góc $B$. Khi đó ta có: $\left. \left. \frac { DA } { DC }=\frac { BA } { BC }=\frac { 1 } { 2 }⇔DC=2DA⇔\overset\rightarrow { DC }=-2\overset\rightarrow { DA }\left ( { * } \right.  ) \right. \right.$ $\left. \left. \overset\rightarrow { DC }=\left ( { -4-a;7-b;5-c } \right.  ),\overset\rightarrow { DA }=\left ( { 1-a;2-b;-1-c } \right.  ) \right. \right.$ $\left ( { * } \right.  )⇔\left\{ \begin{array}{l} -4-a=-2\left ( { 1-a } \right.  )7-b=-2\left ( { 2-b } \right.  )5-c=-2\left ( { -1-c } \right.  ) \end{array} \right.⇔\left\{ \begin{array}{l} a=\frac { -2 } { 3 }b=\frac { 11 } { 3 }c=1 \end{array} \right.$ $T=a+b+c=\frac { -2 } { 3 }+\frac { 11 } { 3 }+1=4.$ -----------------------------Hết-----------------------------

</details>
