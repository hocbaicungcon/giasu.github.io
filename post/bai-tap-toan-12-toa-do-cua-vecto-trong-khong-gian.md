# Bài tập Toán 12: Tọa độ của vectơ trong không gian

> **Tóm tắt chuyên đề:** Bài tập Tọa độ của điểm và tọa độ của vectơ trong hệ tọa độ $Oxyz$ Toán 12: công thức xác định tọa độ, độ dài vectơ, khoảng cách giữa hai điểm có bài tập và đáp án chi tiết.

## I. Lý thuyết trọng tâm cần nhớ

### 1. Hệ tọa độ trong không gian.

> **Định nghĩa:** Trong không gian, cho ba trục $Ox,Oy,Oz$ đôi một vuông góc. » Gọi $i,j,k$ lần lượt là ba vectơ đơn vị trên các trục $Ox,Oy,Oz$.» Hệ ba trục như vậy được gọi là hệ trục tọ̣a độ Descartes vuông gócOxyztrong không gian hay gọi đơn giản hệ tọa độ $Oxyz$.

<p align="center"><img src="/assets/images/toan-12/c2_b2_image9.png" alt="Hình vẽ minh họa" style="max-width: min(100%, 480px); height: auto; border-radius: 8px;" /></p>

### 2. Tọa độ của điểm và vectơ.

Tọa độ điểmTrong không gian $Oxyz$, cho điểm $M$.» Nếu $\overrightarrow { OM }=xi+yj+zk$ thì ta gọi bộ ba số $\left ( { x;y;z } \right.  )$ là tọa độ của điểm $M$ đối với hệ trục toạ độ $Oxyz$.» Viết $M=\left ( { x;y;z } \right.  )$ hoặc $M\left ( { x;y;z } \right.  )$; Trong đó $x$ là hoành độ,$y$ là tung độ,$z$ là cao độ của điểm $M$.

<p align="center"><img src="/assets/images/toan-12/c2_b2_image24.png" alt="Hình vẽ minh họa" style="max-width: min(100%, 480px); height: auto; border-radius: 8px;" /></p>

Tọa độ vectoTrong không gian $Oxyz$, cho vectơ $a$. » Nếu $a=a_{ 1 } i+a_{ 2 } j+a_{ 3 } k$ thì ta gọi bộ ba số $\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ là tọ độ của vectơ $a$ đối với hệ toạ độ $Oxyz$» Viết $a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ hoặc $a\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  );$. Trong đó $a_{ 1 }$ là hoành độ,$a_{ 2 }$ là tung độ,$a_{ 3 }$ là cao độ của vectơ $a$.
## II. Phân dạng bài tập & Phương pháp giải

### Dạng 1. Tọa độ điểm

» Nếu $a=a_{ 1 } i+a_{ 2 } j+a_{ 3 } k$ thì $a=\left ( { a_{ 1 } \,;\,a_{ 2 } \,;\,a_{ 3 } } \right.  )$.» Nếu $\overrightarrow { OM }=m_{ 1 } i+m_{ 2 } j+m_{ 3 } k$ thì $\overrightarrow { OM }=\left ( { m_{ 1 } ;m_{ 2 } ;m_{ 3 } } \right.  )⇒M\left ( { m_{ 1 } ;m_{ 2 } ;m_{ 3 } } \right.  )$.» Nếu $\overrightarrow { MO }=m_{ 1 } i+m_{ 2 } j+m_{ 3 } k$ thì $\overrightarrow { MO }=\left ( { m_{ 1 } ;m_{ 2 } ;m_{ 3 } } \right.  )⇒M\left ( { -m_{ 1 } ;-m_{ 2 } ;-m_{ 3 } } \right.  )$.⑴$M$ thuộc các trục tọa độ:$\left | { M∈Ox→M\left ( { x\,;0\,;0 } \right.  )M∈Oy→M\left ( { 0\,;y\,;0 } \right.  )M∈Oz→M\left ( { 0\,;0\,;z } \right.  ) } \right.  .$⑵$M$ thuộc các mặt phẳng tọa độ:$\left | { M∈\left ( { Oxy } \right.  )→M\left ( { x\,;y;0 } \right.  )M∈\left ( { Oxz } \right.  )→M\left ( { x\,;0\,;z } \right.  )M∈\left ( { Oyz } \right.  )→M\left ( { 0\,;y\,;z } \right.  ) } \right.  .$ Phương pháp

**Ví dụ 1.1.** Xác định tọa độ điểm $M$ trong các trường hợp sau⑴$\overrightarrow { MO }=2i-3k$⑵$\left. \overrightarrow { OM }=2\overrightarrow { OA }+i \right.$ với $A\left ( { 2;-3;1 } \right.  )$

*Lời giải:*

⑴$\overrightarrow { MO }=2i-3k$

Ta có $\overrightarrow { OM }=-2i+3k$. Do đó $M\left ( { -2;0;3 } \right.  )$.

⑵$\left. \overrightarrow { OM }=2\overrightarrow { OA }+i \right.$ với $A\left ( { 2;-3;1 } \right.  )$

Ta có $\overrightarrow { OM }=2\left ( { 2i-3j+k } \right.  )+3k=4i-4j+5k$. Vậy $M\left ( { 4;-4;5 } \right.  )$.

**Ví dụ 1.2.** Trong không gian $Oxyz$, cho hai điểm $M\left ( { -4;3;-1 } \right.  )$ và $N\left ( { 2;-1;-3 } \right.  )$. Tìm tọa độ của các vectơ $\left. \overrightarrow { OM },\overrightarrow { ON } \right.$.

*Lời giải:*

Ta có:$M\left ( { -4;3;-1 } \right.  )$ và $N\left ( { 2;-1;-3 } \right.  )$.

Do đó,$\left. \overrightarrow { OM }=\left ( { -4;3;-1 } \right.  );\overrightarrow { ON }=\left ( { 2;-1;-3 } \right.  ) \right.$.

**Ví dụ 1.3.** Cho điểm $M\left ( { -2;5;3 } \right.  )$. Tìm hình chiếu vuông góc của điểm $M$ trên các trục tọa độ.

*Lời giải:*

Gọi:

$M'\left ( { x';y';z' } \right.  )$ là hình chiếu vuông góc của điểm $M$ trên trục $Ox$.

$M'$ là hình chiếu vuông góc của điểm $M$ trên trục $Oy$.

$M'$ là hình chiếu vuông góc của điểm $M$ trên trục $Oz$.

Khi đó $M'\left ( { -2;0;0 } \right.  )$;$M'$;$M'$.

**Ví dụ 1.4.** Trong không gian $Oxyz$, cho điểm $A\left ( { 1;2;-3 } \right.  )$ và vectơ $u=\left ( { 3;-4;2 } \right.  )$. Hãy biểu diễn theo các vectơ $i,j$ và $k$ mỗi vectơ sau:⑴$\overrightarrow { OA }$⑵$u$

*Lời giải:*

⑴$\overrightarrow { OA }$

Vì điểm $A$ có toạ độ là $A\left ( { 1;2;-3 } \right.  )$ nên $\overrightarrow { OA }=\left ( { 1;2;-3 } \right.  )$

Do đó,$\overrightarrow { OA }=1i+2j+\left ( { -3 } \right.  )k=i+2j-3k$.

⑵$u$

Vì $u=\left ( { 3;-4;2 } \right.  )$ nên $u=3i+\left ( { -4 } \right.  )j+2k=3i-4j+2k.$

**Ví dụ 1.4.** Trong không gian $Oxyz$, cho tọa độ $A\left ( { 4;5;3 } \right.  )$ và vị trí các điểm $L;K;H;A_{ 1 } ;A_{ 2 } ;A_{ 3 }$ như hình vẽ bên. Xác định tọa độ của các vectơ $\left. \overrightarrow { A_{ 1 } A },\overrightarrow { A_{ 2 } A } \right.$<p align="center"><img src="/assets/images/toan-12/c2_b2_image93.png" alt="Hình vẽ minh họa" style="max-width: min(100%, 480px); height: auto; border-radius: 8px;" /></p>

*Lời giải:*

Từ hình vẽ, ta có:$\left. \left. \left. \overrightarrow { A_{ 1 } A }=\overrightarrow { OL };\,\,\overrightarrow { A_{ 2 } A }=\overrightarrow { OH } \right. \right. \right.$

Mà $\left. L\left ( { 0;0;3 } \right.  )⇒\overrightarrow { OL }=\left ( { 0;0;3 } \right.  ) \right.$ và $\left. H\left ( { 4;0;0 } \right.  )⇒\overrightarrow { OH }=\left ( { 4;0;0 } \right.  ) \right.$.

Do đó,$\overrightarrow { A_{ 1 } A }=\left ( { 0;0;3 } \right.  )$ và $\overrightarrow { A_{ 2 } A }=\left ( { 4;0;0 } \right.  )$.

### Dạng 2. Tọa độ vectơ

Xét hai véctơ $a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ và $b=\left ( { b_{ 1 } ;b_{ 2 } ;b_{ 3 } } \right.  )$ ta có:⑴ Hai véctơ bằng nhau:$a=b⇔\left\{ \begin{array}{l} a_{ 1 } =b_{ 1 } a_{ 2 } =b_{ 2 } a_{ 3 } =b_{ 3 } \end{array} \right.$.⑵ABCDlà hình bình hành $\left. \overrightarrow { AB }=\overrightarrow { DC } \right.$. Phương pháp

**Ví dụ 2.1.** Trong không gian $Oxyz$, cho $a=3i+2j-k$⑴ Xác định tọa độ vectơ $a$.⑵ Tìm $x;y;z$ để $b=\left ( { x+2y-z-1;x-y+3z+1;3x-y-z-6 } \right.  )$ bằng $a$.

*Lời giải:*

⑴ Xác định tọa độ vectơ $a$.

Ta có $a=3i+2j-k=\left ( { 3;2;-1 } \right.  )$.

Ta có $a=b⇔\left\{ \begin{array}{l} x+2y-z-1=3x-y+3z+1=23x-y-z-6=-1 \end{array} \right.$ $⇔\left\{ \begin{array}{l} x=2y=1z=0 \end{array} \right.$.

### Dạng 3. Bài toán thực tế

**Ví dụ 3.1.** Một chiếc xe đang kéo căng sợi dây cáp $AB$ trong công trường xây dựng, trên đó đã thiết lập hệ toạ độOxyznhư hình bên dưới với độ dài đơn vị trên các trục toạ độ bằng $1 { \rm{ m } }$. Tìm tọa độ của vectơ $\overrightarrow { AB }$.

$\left. ⇒\overrightarrow { AB }{ \rm{ } }=\left ( { \frac { 15 } { 2 };\frac { 15\sqrt{ 3 } } { 2 };-10 } \right.  ). \right.$
