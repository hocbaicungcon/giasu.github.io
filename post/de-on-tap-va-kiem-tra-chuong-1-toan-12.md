## V. Bài tập trắc nghiệm Trả lời ngắn (Cấu trúc mới GDPT 2018)

**Câu 1:** Gọi $m,n$ lần lượt là giá trị cực đại và giá trị cực tiểu của hàm số $y=\frac { x ^ { 2 } +x+4 } { x+1 }$. Tính giá trị biểu thức $P=m ^ { 3 } +n ^ { 3 }$.

<details>
<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

Hàm số đã cho có tập xác định là $\mathbb{R}\left\{ \begin{array}{l} -1 \end{array} \right\}$. Ta có:$y'=\frac { x ^ { 2 } +2x-3 } { \left ( { x+1 } \right.  ) ^ { 2 } }$ với $x≠-1$; $y'=0⇔x ^ { 2 } +2x-3=0⇔\left[ x=-3x=1 \right.$ Ta có bảng biến thiên của hàm số như sau <p align="center"><img src="/assets/images/toan-12/c1_ontap_image227.png" alt="Hình vẽ minh họa" style="max-width: min(100%, 480px); height: auto; border-radius: 8px;" /></p> Giá trị cực đại của hàm số bằng $-5$, giá trị cực tiểu của hàm số bằng $3$. Vậy $P=m ^ { 3 } +n ^ { 3 } =\left ( { -5 } \right.  ) ^ { 3 } +3 ^ { 3 } =-98$.

</details>

**Câu 2:** Gọi $m,M$ lần lượt là giá trị nhỏ nhất và giá trị lớn nhất của hàm số $y=\frac { 4 } { 3 }sin ^ { 3 } x+4cos ^ { 2 } x-5sinx+1$. Tính giá trị của $M-m$.

<details>
<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

$y=\frac { 4 } { 3 }sin ^ { 3 } x+4cos ^ { 2 } x-5sinx+1=\frac { 4 } { 3 }sin ^ { 3 } x-4sin ^ { 2 } x-5sinx+5$ Đặt $t=sinx⇒t∈\left[ -1;1 \right]$. Khi đó, bài toán trở thành tìm GTLN, GTNN của hàm số $g(t)=\frac { 4 } { 3 }t ^ { 3 } -4t ^ { 2 } -5t+5$ trên đoạn $\left[ -1;1 \right]$ Xét hàm số $g(t)=\frac { 4 } { 3 }t ^ { 3 } -4t ^ { 2 } -5t+5$ trên đoạn $\left[ -1;1 \right]$. Ta có $g'(t)=4t ^ { 2 } -8t-5$,$g'(t)=0⇔\left[ t=\frac { -1 } { 2 }∈\left[ -1;1 \right]t=\frac { 5 } { 2 }∉\left[ -1;1 \right] \right.$ $g(-1)=\frac { 14 } { 3 },g\left ( { -\frac { 1 } { 2 } } \right.  )=\frac { 19 } { 3 },g(1)=\frac { -8 } { 3 }.$ Vậy $M=\mathop { max } \limits_{ \left[ -1;1 \right] } g(t)=\frac { 19 } { 3 }$ tại $t=\frac { -1 } { 2 }$,$m=\mathop { min } \limits_{ \left[ -1;1 \right] } g(t)=\frac { -8 } { 3 }$ tại $t=1$. Khi đó $M-m=9$.

</details>

**Câu 3:** Cho đồ thị hàm số $y=f\left ( { x } \right.  )=4x-3+\frac { 1 } { x-2 }$ có tâm đối xứng $I\left ( { a;b } \right.  )$. Giá trị của biểu thức $a-3b$ là bao nhiêu?

<details>
<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

Ta có $a=\mathop { lim } \limits_{ x→+∞ } \frac { f\left ( { x } \right.  ) } { x }=\mathop { lim } \limits_{ x→+∞ } \left[ 4-\frac { 3 } { x }+\frac { 1 } { x\left ( { x-2 } \right.  ) } \right]$ $=4$. Ta có $b=\mathop { lim } \limits_{ x→+∞ } \left[ f\left ( { x } \right.  )-4x \right]=\mathop { lim } \limits_{ x→+∞ } \left ( { 4x-3+\frac { 1 } { x-2 }-4x } \right.  )$ $=-3$. Do đó, đồ thị hàm số có tiệm cận xiên là $y=4x-3$. Mặt khác,$\mathop { lim } \limits_{ x→2 ^ { + } } \left ( { 4x-3+\frac { 1 } { x-2 } } \right.  )=+∞$ do đó $x=2$ là tiệm cận dứng của đồ thị hàm số. Ta có tâm đối xứng của đồ thị hàm số trên là giao điểm của $y=4x-3$ và $x=2$; vậy ta được $I\left ( { 2;5 } \right.  )$. Suy ra $a-3b=2-3.5=-13$.

</details>

**Câu 4:** Hằng ngày mực nước của hồ thủy điện ở miền Trung lên và xuống theo lượng nước mưa, và các suối nước đổ về hồ. Từ lúc 8h sáng, độ sâu của mực nước trong hồ tính theo mét và lên xuống theo thời gian t (giờ) trong ngày cho bởi công thức $h\left ( { t } \right.  )=24t+5t ^ { 2 } -\frac { t ^ { 3 } } { 3 }$. Biết rằng phải thông báo cho các hộ dân phải di dời trước khi xả nước theo quy định trước 5 giờ. Hỏi cần thông báo cho hộ dân di dời trước khi xả nước mấy giờ. Biết rằng mực nước trong hồ phải lên cao nhất mới xả nước.

<details>
<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

Ta có: $h'\left ( { t } \right.  )=24+10t-t ^ { 2 } h'\left ( { t } \right.  )=0⇔24+10t-t ^ { 2 } =0⇔\left[ t=-2(loai)t=12{ \rm{ } }{ \rm{ } }(t/m) \right.$ BBT: Vậy để mực nước lên cao nhất thì phải mất $12$ giờ. Vậy phải thông báo cho dân di dời vào $15$ giờ chiều cùng ngày.

**Câu 6:** Một công ty kinh doanh bất động sản có $20$ căn hộ cho thuê. Biết rằng nếu cho thuê mỗi căn hộ với giá 2 triệu đồng/1 tháng thì tất cả các căn hộ đều có người thuê. Nhưng cứ mỗi lần tăng giá cho thuê mỗi căn hộ thêm $200$ nghìn đồng/1 tháng thì có thêm một căn hộ bị bỏ trống. Hỏi công ty nên cho thuê mỗi căn hộ bao nhiêu triệu đồng một tháng để tổng số tiền thu được là lớn nhất?

<details>
<summary><b>Xem đáp số & lời giải chi tiết</b></summary>

Cứ tăng thêm 200 nghìn đồng vào giá thuê một căn hộ trên một tháng thì có một căn hộ bị bỏ trống. Gọi số lần tăng 200 nghìn đồng vào giá thuê một căn hộ trên một tháng là x (x ∈ ℕ*). Khi đó x cũng là số căn hộ bị bỏ trống. Tổng số tiền công ty thu được lúc này là $T\left ( { x } \right.  )=\left ( { 2000+200x } \right.  )\left ( { 20–x } \right.  )=40000+2000x–200x ^ { 2 }$ (nghìn đồng). Xét hàm số $T\left ( { x } \right.  )=40000+2000x–200x ^ { 2 }$ với $x∈\mathbb{N} ^ { * }$. Ta có $T'\left ( { x } \right.  )=2000–400x$; $T'\left ( { x } \right.  )=0⇔2000–400x=0⇔x=5$ (thỏa mãn). Bảng biến thiên của hàm số $T\left ( { x } \right.  )$ như sau: <p align="center"><img src="/assets/images/toan-12/c1_ontap_image295.png" alt="Hình vẽ minh họa" style="max-width: min(100%, 480px); height: auto; border-radius: 8px;" /></p> Căn cứ vào bảng biến thiên trên, ta thấy hàm số $T\left ( { x } \right.  )$ đạt giá trị lớn nhất bằng $45000$ khi $x=5.$ Khi đó, số tiền tăng lên khi cho thuê một căn hộ là $200.5=1000$ nghìn đồng = 1 triệu đồng. Vậy công ty nên cho thuê mỗi căn hộ 3 triệu đồng/1 tháng thì tổng số tiền thu được là lớn nhất. -----------------------------Hết-----------------------------

</details>
