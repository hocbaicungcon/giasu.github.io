# Ôn tập Chương 3. Hệ thức lượng trong tam giác

Chương 3 khép lại phần lượng giác và hệ thức lượng cơ bản trong tam giác — cầu nối quan trọng giữa hình học thuần túy và các bài toán đo đạc kỹ thuật thực tế. Bài tổng ôn tập này giúp các em làm chủ trọn vẹn các công thức định lí sin, định lí côsin, diện tích tam giác và thử sức với đề kiểm tra 45 phút chuẩn ma trận Bộ GD&ĐT.

---

## 1. Bảng tra cứu toàn diện công thức Chương 3

| Nhóm công thức | Công thức toán học chuẩn | Ý nghĩa & Khi nào sử dụng |
| :--- | :--- | :--- |
| **Giá trị lượng giác góc bù** | $\sin(180^\circ - \alpha) = \sin\alpha$<br>$\cos(180^\circ - \alpha) = -\cos\alpha$<br>$\tan(180^\circ - \alpha) = -\tan\alpha$ | Chuyển góc tù về góc nhọn tương ứng |
| **Hệ thức cơ bản** | $\sin^2\alpha + \cos^2\alpha = 1$<br>$1 + \tan^2\alpha = \frac{1}{\cos^2\alpha}$<br>$\tan\alpha \cdot \cot\alpha = 1$ | Biến đổi và tính các giá trị lượng giác khi biết một giá trị |
| **Định lí Côsin** | $a^2 = b^2 + c^2 - 2bc\cos A$<br>$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$ | Tính cạnh thứ 3 khi biết 2 cạnh + góc kẹp giữa, hoặc tính góc khi biết 3 cạnh |
| **Đường trung tuyến** | $m_a^2 = \frac{2(b^2 + c^2) - a^2}{4}$ | Tính độ dài trung tuyến kẻ từ đỉnh $A$ |
| **Định lí Sin** | $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ | Tính cạnh khi biết 2 góc + 1 cạnh, tính bán kính ngoại tiếp $R = \frac{a}{2\sin A}$ |
| **5 công thức Diện tích** | 1. $S = \frac{1}{2}ah_a$<br>2. $S = \frac{1}{2}ab\sin C$<br>3. $S = \frac{abc}{4R} \Rightarrow R = \frac{abc}{4S}$<br>4. $S = pr \Rightarrow r = \frac{S}{p}$ ($p = \frac{a+b+c}{2}$)<br>5. Heron: $S = \sqrt{p(p-a)(p-b)(p-c)}$ | Tính diện tích theo các dữ kiện đã cho; tính bán kính nội tiếp $r$ và ngoại tiếp $R$ |

## 4. Phần II: Tự luận phân hóa (7,0 điểm - 4 bài toán)

### Bài 1 (1,5 điểm - Mức độ Thông hiểu)
Cho góc $\alpha$ thỏa mãn $\cos\alpha = -\frac{1}{3}$ với $0^\circ < \alpha < 180^\circ$.
1. Tính $\sin\alpha, \tan\alpha$ và $\cot\alpha$. *(0,75 điểm)*
2. Rút gọn và tính giá trị của biểu thức: *(0,75 điểm)*
   $$P = \frac{3\sin\alpha + 2\cos(180^\circ - \alpha)}{\sin(180^\circ - \alpha) - \cos\alpha}$$

---

### Bài 2 (1,5 điểm - Mức độ Vận dụng)
Cho tam giác $ABC$ có $AB = 6, AC = 10$ và góc $\widehat{A} = 120^\circ$.
1. Tính độ dài cạnh $BC$. *(0,75 điểm)*
2. Tính diện tích tam giác $ABC$ và bán kính đường tròn ngoại tiếp $R$ của tam giác $ABC$. *(0,75 điểm)*

---

### Bài 3 (2,0 điểm - Mức độ Vận dụng)
Cho tam giác $ABC$ có ba cạnh $a = 7, b = 8, c = 9$.
1. Tính diện tích tam giác $ABC$ theo công thức Heron. *(0,75 điểm)*
2. Tính bán kính đường tròn nội tiếp $r$ và bán kính đường tròn ngoại tiếp $R$ của tam giác $ABC$. *(0,75 điểm)*
3. Tính độ dài đường cao $h_a$ và độ dài đường trung tuyến $m_a$ kẻ từ đỉnh $A$. *(0,5 điểm)*

---

### Bài 4 (2,0 điểm - Mức độ Vận dụng cao)
Để ước lượng khoảng cách giữa hai hòn đảo nhỏ $A$ và $B$ trên biển, một hoa tiêu đứng tại đài quan sát $C$ trên bờ biển.  
Người đó đo được:
- Khoảng cách từ đài $C$ đến đảo $A$ là $CA = 12$ km.
- Khoảng cách từ đài $C$ đến đảo $B$ là $CB = 16$ km.
- Góc quan sát giữa hai đảo từ vị trí $C$ là $\widehat{ACB} = 60^\circ$.

1. *(1,0 điểm)* Tính khoảng cách đường chim bay giữa hai hòn đảo $A$ và $B$.
2. *(1,0 điểm)* Một con tàu cứu hộ xuất phát từ vị trí $M$ là trung điểm của đoạn thẳng $AB$ chạy thẳng về trạm bờ $C$. Hãy tính quãng đường mà con tàu cứu hộ cần di chuyển (tức độ dài đoạn thẳng $CM$).

## 5. Lời giải chi tiết & Barem chấm điểm phần Tự luận

### Hướng dẫn chấm Bài 1 (1,5 điểm)

| Ý | Nội dung giải chi tiết | Điểm |
| :---: | :--- | :---: |
| **1** | - Ta có $\sin^2\alpha = 1 - \cos^2\alpha = 1 - \left(-\frac{1}{3}\right)^2 = 1 - \frac{1}{9} = \frac{8}{9}$.<br>Vì $0^\circ < \alpha < 180^\circ \Rightarrow \sin\alpha > 0$.<br>Do đó: $\sin\alpha = \sqrt{\frac{8}{9}} = \frac{2\sqrt{2}}{3}$. | 0,25đ |
| | - Tính $\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{\frac{2\sqrt{2}}{3}}{-\frac{1}{3}} = -2\sqrt{2}$. | 0,25đ |
| | - Tính $\cot\alpha = \frac{1}{\tan\alpha} = -\frac{1}{2\sqrt{2}} = -\frac{\sqrt{2}}{4}$. | 0,25đ |
| **2** | - Dùng tính chất góc bù: $\sin(180^\circ - \alpha) = \sin\alpha$ và $\cos(180^\circ - \alpha) = -\cos\alpha$.<br>Biểu thức trở thành:<br>$$P = \frac{3\sin\alpha + 2(-\cos\alpha)}{\sin\alpha - \cos\alpha} = \frac{3\sin\alpha - 2\cos\alpha}{\sin\alpha - \cos\alpha}$$ | 0,25đ |
| | - Thay $\sin\alpha = \frac{2\sqrt{2}}{3}$ và $\cos\alpha = -\frac{1}{3}$ vào:<br>Tử số: $3\left(\frac{2\sqrt{2}}{3}\right) - 2\left(-\frac{1}{3}\right) = 2\sqrt{2} + \frac{2}{3} = \frac{6\sqrt{2} + 2}{3}$.<br>Mẫu số: $\frac{2\sqrt{2}}{3} - \left(-\frac{1}{3}\right) = \frac{2\sqrt{2} + 1}{3}$. | 0,25đ |
| | - Suy ra:<br>$$P = \frac{6\sqrt{2} + 2}{2\sqrt{2} + 1} = \frac{2(3\sqrt{2} + 1)}{2\sqrt{2} + 1} = \frac{2(3\sqrt{2} + 1)(2\sqrt{2} - 1)}{(2\sqrt{2})^2 - 1^2} = \frac{2(12 - 3\sqrt{2} + 2\sqrt{2} - 1)}{7} = \frac{2(11 - \sqrt{2})}{7} = \frac{22 - 2\sqrt{2}}{7}$$ | 0,25đ |

### Hướng dẫn chấm Bài 2 (1,5 điểm)

| Ý | Nội dung giải chi tiết | Điểm |
| :---: | :--- | :---: |
| **1** | - Tam giác $ABC$ có $c = AB = 6, b = AC = 10$ và $\widehat{A} = 120^\circ$.<br>Theo định lí côsin:<br>$$a^2 = BC^2 = b^2 + c^2 - 2bc\cos A$$<br>$$BC^2 = 10^2 + 6^2 - 2(10)(6)\cos 120^\circ$$ | 0,25đ |
| | - Ta có $\cos 120^\circ = -\frac{1}{2}$, thay vào:<br>$$BC^2 = 100 + 36 - 120\left(-\frac{1}{2}\right) = 136 + 60 = 196$$<br>Suy ra $BC = \sqrt{196} = 14$. | 0,5đ |
| **2** | - Diện tích tam giác $ABC$:<br>$$S = \frac{1}{2}bc\sin A = \frac{1}{2} \cdot 10 \cdot 6 \cdot \sin 120^\circ = 30 \cdot \frac{\sqrt{3}}{2} = 15\sqrt{3}$$ | 0,25đ |
| | - Bán kính đường tròn ngoại tiếp $R$:<br>Áp dụng định lí sin: $2R = \frac{a}{\sin A} = \frac{14}{\sin 120^\circ} = \frac{14}{\frac{\sqrt{3}}{2}} = \frac{28}{\sqrt{3}}$<br>Suy ra $R = \frac{14}{\sqrt{3}} = \frac{14\sqrt{3}}{3} \approx 8,08$. | 0,5đ |

### Hướng dẫn chấm Bài 3 (2,0 điểm)

| Ý | Nội dung giải chi tiết | Điểm |
| :---: | :--- | :---: |
| **1** | - Nửa chu vi $p = \frac{a + b + c}{2} = \frac{7 + 8 + 9}{2} = \frac{24}{2} = 12$.<br>Các hiệu số: $p - a = 12 - 7 = 5$; $p - b = 12 - 8 = 4$; $p - c = 12 - 9 = 3$. | 0,25đ |
| | - Áp dụng công thức Heron:<br>$$S = \sqrt{p(p - a)(p - b)(p - c)} = \sqrt{12 \cdot 5 \cdot 4 \cdot 3} = \sqrt{720} = \sqrt{144 \cdot 5} = 12\sqrt{5}$$ | 0,5đ |
| **2** | - Bán kính đường tròn nội tiếp $r$:<br>$$r = \frac{S}{p} = \frac{12\sqrt{5}}{12} = \sqrt{5}$$ | 0,25đ |
| | - Bán kính đường tròn ngoại tiếp $R$:<br>$$R = \frac{abc}{4S} = \frac{7 \cdot 8 \cdot 9}{4 \cdot 12\sqrt{5}} = \frac{504}{48\sqrt{5}} = \frac{21}{2\sqrt{5}} = \frac{21\sqrt{5}}{10} \approx 4,70$$ | 0,5đ |
| **3** | - Đường cao $h_a$:<br>$$S = \frac{1}{2}a \cdot h_a \Rightarrow h_a = \frac{2S}{a} = \frac{2 \cdot 12\sqrt{5}}{7} = \frac{24\sqrt{5}}{7}$$ | 0,25đ |
| | - Đường trung tuyến $m_a$ kẻ từ đỉnh $A$:<br>$$m_a^2 = \frac{2(b^2 + c^2) - a^2}{4} = \frac{2(8^2 + 9^2) - 7^2}{4} = \frac{2(64 + 81) - 49}{4} = \frac{2(145) - 49}{4} = \frac{290 - 49}{4} = \frac{241}{4}$$<br>Suy ra $m_a = \frac{\sqrt{241}}{2} \approx 7,76$. | 0,25đ |
