# Bài tập Toán 12: Giá trị lớn nhất và nhỏ nhất của hàm số

> **Tóm tắt chuyên đề:** Tổng hợp bài tập Giá trị lớn nhất và nhỏ nhất của hàm số Toán 12 chương trình GDPT mới gồm lý thuyết trọng tâm, các dạng bài tập tìm max min, trắc nghiệm tự chấm và đáp án chi tiết.

## I. Lý thuyết trọng tâm cần nhớ

### 1. Định nghĩa

> **Định nghĩa:** Cho hàm số $y=f\left ( { x } \right.  )$ xác định trên D Số M được gọi là giá trị lớn nhất (GTLN) của hàm số $y=f\left ( { x } \right.  )$ trên $D$ nếu $\left\{ \begin{array}{l} f\left ( { x } \right.  )≤M;∀x∈D∃x_{ 0 } ∈D:f\left ( { x_{ 0 } } \right.  )=M \end{array} \right.,$ ta kí hiệu $M=\mathop { max } \limits_{ x∈D } f\left ( { x } \right.  )$ hoặc $M=\mathop { max } \limits_{ D } f\left ( { x } \right.  )$. Số m được gọi là giá trị nhỏ nhất (GTNN) của hàm số $y=f\left ( { x } \right.  )$ trên D nếu $\left\{ \begin{array}{l} f\left ( { x } \right.  )≥M;∀x∈D∃x_{ 0 } ∈D:f\left ( { x_{ 0 } } \right.  )=M \end{array} \right.,$ ta kí hiệu $m=\mathop { min } \limits_{ x∈D } f\left ( { x } \right.  )$ hoặc $m=\mathop { min } \limits_{ D } f\left ( { x } \right.  )$.

» Quy ước rằng khi nói GTLN và GTNN của hàm số $y=f\left ( { x } \right.  )$ (mà không xét “trên tập $D$”) thì ta hiểu đó là GTLN hay GTNN của $y=f\left ( { x } \right.  )$ trên tập xác định của hàm số. » Để tìm GTLN hay GTNN của hàm số trên tập $D$, ta thường lập bảng biến thiên của hàm số trên tập $D$ để kết luận. Chú ý

### 2. Tìm giá trị lớn nhất – nhỏ nhất trên đoạn

Cách tìm giá trị lớn nhất – nhỏ nhất trên đoạn. Tìm giá trị lớn nhất, giá trị nhỏ nhất của hàm số $f\left ( { x } \right.  )$ liên tục trên đoạn $\left[ a;b \right]$: Bước 1: Tìm các điểm $x_{ 1 } ;x_{ 2 } ;...;x_{ n }$ thuộc $\left ( { a;b } \right.  )$ sao cho $f'\left ( { x } \right.  )=0$. Bước 2: Tính $f\left ( { a } \right.  );f\left ( { x_{ 1 } } \right.  );f\left ( { x_{ 2 } } \right.  );...;f\left ( { x_{ n } } \right.  );f\left ( { b } \right.  )$. Bước 3: Gọi $M$ là số lớn nhất và $m$ là số nhỏ nhất trong các giá trị ở Bước 2. Khi đó $M=\mathop { max } \limits_{ \left[ a;b \right] } f\left ( { x } \right.  )$ và $m=\mathop { min } \limits_{ \left[ a;b \right] } f\left ( { x } \right.  )$.

### Dạng 1. Giá trị lớn nhất – nhỏ nhất của hàm số trên đoạn

**Ví dụ 1.1.** Tìm giá trị lớn nhất và nhỏ nhất của hàm số $f\left ( { x } \right.  )=x ^ { 3 } -3x+1$ trên đoạn $\left[ -2;2 \right]$.

*Lời giải:*

Ta có:$f'\left ( { x } \right.  )=0⇔3x ^ { 2 } -3=0⇔\left[ x=1\,\,\left ( { n } \right.  )x=-1\,\left ( { n } \right.  ) \right.$

Ta có:$f\left ( { -2 } \right.  )=-1;\,\,f\left ( { -1 } \right.  )=3;\,\,f\left ( { 1 } \right.  )=-1;\,\,f\left ( { 2 } \right.  )=3$

Vậy $\mathop { max } \limits_{ \left[ -2;2 \right] } f\left ( { x } \right.  )=3$ khi $\left[ x=-1x=2 \right.$ và $\mathop { min } \limits_{ \left[ -2;2 \right] } f\left ( { x } \right.  )=-1$ khi $\left[ x=-2x=1 \right.$.

**Ví dụ 1.2.** Tìm giá trị lớn nhất và nhỏ nhất của hàm số $f\left ( { x } \right.  )=x\sqrt{ 1-x ^ { 2 } }$

*Lời giải:*

Điều kiện:$1-x ^ { 2 } ≥0⇔-1≤x≤1$.

Ta có:$f'\left ( { x } \right.  )=0⇔\sqrt{ 1-x ^ { 2 } }+x.\frac { -x } { \sqrt{ 1-x ^ { 2 } } }=0⇔1-x ^ { 2 } -x ^ { 2 } =0⇔\left[ x=\frac { -\sqrt{ 2 } } { 2 }\,\,\left ( { n } \right.  )x=\frac { \sqrt{ 2 } } { 2 }\,\,\left ( { n } \right.  ) \right.$

Ta có:$f\left ( { -1 } \right.  )=0;\,\,f\left ( { \frac { -\sqrt{ 2 } } { 2 } } \right.  )=\frac { -1 } { 2 };\,\,f\left ( { \frac { \sqrt{ 2 } } { 2 } } \right.  )=\frac { 1 } { 2 };\,\,f\left ( { 1 } \right.  )=0$

Vậy $\mathop { max } \limits_{ \left[ -1;1 \right] } f\left ( { x } \right.  )=\frac { 1 } { 2 }$ khi $x=\frac { \sqrt{ 2 } } { 2 }$ và $\mathop { min } \limits_{ \left[ -1;1 \right] } f\left ( { x } \right.  )=\frac { -1 } { 2 }$ khi $x=\frac { -\sqrt{ 2 } } { 2 }$.

**Câu 15:** Hai thành phố A và B cách nhau một con sông.
