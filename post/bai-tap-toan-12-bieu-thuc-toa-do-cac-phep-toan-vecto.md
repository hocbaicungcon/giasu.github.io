# Bài tập Toán 12: Biểu thức tọa độ của các phép toán vectơ

> **Tóm tắt chuyên đề:** Biểu thức tọa độ của các phép toán vectơ: cộng trừ vectơ, tích vô hướng, góc giữa hai vectơ, vectơ cùng phương trong không gian $Oxyz$ Toán 12 có bài tập và đáp án chi tiết.

## I. Lý thuyết trọng tâm cần nhớ

### 1. Biểu thức tọa độ của tổng, hiệu hai vectơ và tích của một số với một vectơ

> **Định nghĩa:** Trong không gian $Oxyz$, cho hai vectơ $a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ và $b=\left ( { b_{ 1 } ;b_{ 2 } ;b_{ 3 } } \right.  )$ và số $k$. Khi đó:

- $a+b=\left ( { a_{ 1 } +b_{ 1 } ;a_{ 2 } +b_{ 2 } ;a_{ 3 } +b_{ 3 } } \right.  )$
- $a-b=\left ( { a_{ 1 } -b_{ 1 } ;a_{ 2 } -b_{ 2 } ;a_{ 3 } -b_{ 3 } } \right.  )$
- $ka=\left ( { ka_{ 1 } ;ka_{ 2 } ;ka_{ 3 } } \right.  )$

> **Nhận xét:**  Hai vectơ $a;b$ với $b≠0$ cùng phương $a=k.b⇔\left\{ \begin{array}{l} a_{ 1 } =k.b_{ 1 } a_{ 2 } =k.b_{ 2 } a_{ 3 } =k.b_{ 3 } \end{array} \right.$
- Từ nay, các bài tập liên quan đến toạ độ đều được xét trong không gian $Oxyz$. Chú ý

### 2. Biểu thức tọa độ của tích vô hướng

> **Định nghĩa:** Trong không gian $Oxyz$, tích vô hướng của hai vectơ $a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ và $b=\left ( { b_{ 1 } ;b_{ 2 } ;b_{ 3 } } \right.  )$ được xác định bởi công thức $a⋅b=a_{ 1 } b_{ 1 } +a_{ 2 } b_{ 2 } +a_{ 3 } b_{ 3 } .$

### 3. Vận dụng

Tọa độ điểm đầu cuối:Trong không gian $Oxyz$, cho hai điểm $A\left ( { x_{ A } ;y_{ A } ;z_{ A } } \right.  ),B\left ( { x_{ B } ;y_{ B } ;z_{ B } } \right.  )$. Ta có:$\overrightarrow { AB }=\left ( { x_{ B } -x_{ A } ;y_{ B } -y_{ A } ;z_{ B } -z_{ A } } \right.  ).$

Tọa độ trung điểm đoạn thẳng Trong không gian $Oxyz$, cho hai điểm $A\left ( { x_{ A } ;y_{ A } ;z_{ A } } \right.  ),B\left ( { x_{ B } ;y_{ B } ;z_{ B } } \right.  )$. Toạ độ trung điểm $M$ của đoạn thẳng $AB$ là:$M\left ( { \frac { x_{ A } +x_{ B } } { 2 };\frac { y_{ A } +y_{ B } } { 2 };\frac { z_{ A } +z_{ B } } { 2 } } \right.  )$

Tọa độ trọng tâm tâm giácTrong không gian $Oxyz$, choΔABCcó $A\left ( { x_{ A } ;y_{ A } ;z_{ A } } \right.  ),B\left ( { x_{ B } ;y_{ B } ;z_{ B } } \right.  )$ và $C\left ( { x_{ C } ;y_{ C } ;z_{ C } } \right.  )$. Tọa độ trọng tâm $G$ củaΔABClà:$G\left ( { \frac { x_{ A } +x_{ B } +x_{ C } } { 3 };\frac { y_{ A } +y_{ B } +y_{ C } } { 3 };\frac { z_{ A } +z_{ B } +z_{ C } } { 3 } } \right.  ).$
## II. Phân dạng bài tập & Phương pháp giải

### Dạng 1. Tọa độ tổng hiệu vectơ

Trong không gian $Oxyz$, hai vectơ $a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ và $b=\left ( { b_{ 1 } ;b_{ 2 } ;b_{ 3 } } \right.  )$ và số thực $k$.⑴$a+b=\left ( { a_{ 1 } +b_{ 1 } ;a_{ 2 } +b_{ 2 } ;a_{ 3 } +b_{ 3 } } \right.  )$⑵$a-b=\left ( { a_{ 1 } -b_{ 1 } ;a_{ 2 } -b_{ 2 } ;a_{ 3 } -b_{ 3 } } \right.  )$⑶$ka=\left ( { ka_{ 1 } ;ka_{ 2 } ;ka_{ 3 } } \right.  )$⑷$a$ và $b$ cùng phương $⇔\left\{ \begin{array}{l} a_{ 1 } =kb_{ 1 } a_{ 2 } =kb_{ 2 } a_{ 3 } =kb_{ 3 } \end{array} \right.$ Phương pháp

**Ví dụ 1.1.** Trong không gian $Oxyz$, cho hai vectơ $a=\left ( { 2;-1;5 } \right.  )$ và $b=\left ( { 0;-2;-4 } \right.  )$. Tìm tọa độ của các vectơ sau:$a+b$,$a-b$,$5a$,$2a-\frac { 1 } { 2 }b$.

*Lời giải:*

Ta có:

$a+b=\left ( { 2+0;\left ( { -1 } \right.  )+\left ( { -2 } \right.  );5+\left ( { -4 } \right.  ) } \right.  )=\left ( { 2;-3;1 } \right.  )$.

$a-b=\left ( { 2-0;\left ( { -1 } \right.  )-\left ( { -2 } \right.  );5-\left ( { -4 } \right.  ) } \right.  )=\left ( { 2;1;9 } \right.  )$.

$5a=\left ( { 5.2;5.\left ( { -1 } \right.  );5.5 } \right.  )=\left ( { 10;-5;25 } \right.  )$.

$2a=\left ( { 4;-2;10 } \right.  )$,$\frac { 1 } { 2 }b=\left ( { 0;-1;-2 } \right.  )$. Do đó:$2a-\frac { 1 } { 2 }b=\left ( { 4;-1;12 } \right.  )$.

**Ví dụ 1.2.** Trong không gian $Oxyz$, cho ba điểm $A\left ( { -1;-3;-2 } \right.  )$,$B\left ( { 2;3;4 } \right.  )$ và $C\left ( { 3;5;7 } \right.  )$. Chứng minh rằng ba điểm $A,B,C$ tạo thành tam giác.

*Lời giải:*

Ta có:$\overrightarrow { AB }=\left ( { 3;6;6 } \right.  )$;$\overrightarrow { AC }=\left ( { 4;8;9 } \right.  )$.

Vì $\frac { 3 } { 4 }=\frac { 6 } { 8 }≠\frac { 6 } { 9 }$ nên $\overrightarrow { AB }$ và $\overrightarrow { AC }$ không cùng phương.

Vậy ba điểm $A,B,C$ tạo thành tam giác.

### Dạng 2. Tọa độ điểm – vectơ thỏa điều kiện

⑴ Tích vô hướng của hai vectơ:$a.b=a_{ 1 } a_{ 2 } +b_{ 1 } b_{ 2 } +c_{ 1 } c_{ 2 }$.⑵$a$ và $b$ vuông góc $⇔a.b=0⇔a_{ 1 } a_{ 2 } +b_{ 1 } b_{ 2 } +c_{ 1 } c_{ 2 } =0$⑶$I$ là trung điểm $AB$:$I\left ( { \frac { x_{ A } +x_{ B } } { 2 }\,;\,\frac { y_{ A } +y_{ B } } { 2 }\,;\,\frac { z_{ A } +z_{ B } } { 2 } } \right.  )$ $\left. \left. \left. \left. \left. →\overrightarrow { IA }+\overrightarrow { IB }=0⇒∀M:\overrightarrow { MA }+\overrightarrow { MB }=2\overrightarrow { MI } \right. \right. \right. \right. \right.$⑷$G$ là trọng tâmtam giác $ABC$:$G\left ( { \frac { x_{ A } +x_{ B } +x_{ C } } { 3 }\,;\,\frac { y_{ A } +y_{ B } +y_{ C } } { 3 }\,;\,\frac { z_{ A } +z_{ B } +z_{ C } } { 3 } } \right.  )$ $\left. \left. \left. \left. \left. \left. \left. →\overrightarrow { GA }+\overrightarrow { GB }+\overrightarrow { GC }=0⇒∀M:\overrightarrow { MA }+\overrightarrow { MB }+\overrightarrow { MC }=3\overrightarrow { MG } \right. \right. \right. \right. \right. \right. \right.$⑸$G$ là trọng tâm chópABCD:$G\left ( { \frac { x_{ A } +x_{ B } +x_{ C } +x_{ D } } { 4 }\,;\,\frac { y_{ A } +y_{ B } +y_{ C } +y_{ D } } { 4 }\,;\,\frac { z_{ A } +z_{ B } +z_{ C } +z_{ D } } { 4 } } \right.  )$ $\left. \left. \left. \left. \left. \left. \left. \left. \left. →\overrightarrow { GA }+\overrightarrow { GB }+\overrightarrow { GC }+\overrightarrow { GD }=0⇒∀M:\overrightarrow { MA }+\overrightarrow { MB }+\overrightarrow { MC }+\overrightarrow { MD }=4\overrightarrow { MG } \right. \right. \right. \right. \right. \right. \right. \right. \right.$ Phương pháp

**Ví dụ 2.1.** Trong không gian $Oxyz$, cho ba điểm $A\left ( { 3;2;1 } \right.  )$,$B\left ( { 1;-1;2 } \right.  )$ và $C\left ( { 1;2;-1 } \right.  )$. Tìm tọa độ vectơ $u$ thỏa $\left. \left. u=\overrightarrow { BC }-3\overrightarrow { AO } \right. \right.$.

*Lời giải:*

Ta có:$\overrightarrow { BC }=\left ( { 0;3;-3 } \right.  )$,$\overrightarrow { AO }=\left ( { -3;-2;-1 } \right.  )$.

Do đó:$\left. \left. u=\overrightarrow { BC }-3\overrightarrow { AO }=\left ( { 0-3.\left ( { -3 } \right.  );3-3.\left ( { -2 } \right.  );.\left ( { -1 } \right.  ) } \right.  )=\left ( { 9;9;0 } \right.  ) \right. \right.$.

**Ví dụ 2.2.** Trong không gian $Oxyz$, cho ba điểm $A\left ( { 1;2;-1 } \right.  )$,$B\left ( { 2;-1;3 } \right.  )$ và $C\left ( { -3;5;1 } \right.  )$. Tìm tọa độ điểm $D$ sao cho $\left. \overrightarrow { AB }=2\overrightarrow { DC } \right.$.

*Lời giải:*

Vậy $D\left ( { -\frac { 7 } { 2 };\frac { 13 } { 2 };-1 } \right.  )$.

### Dạng 3. Độ dài vectơ

⑴$\overrightarrow { AB }=\left ( { x_{ B } -x_{ A } ;y_{ B } -y_{ { \rm{ A } } } ;z_{ B } -z_{ A } } \right.  )$ $\left. →AB=\left | { \overrightarrow { AB } } \right.  |=\sqrt{ \left ( { x_{ B } -x_{ A } } \right.  ) ^ { 2 } +\left ( { y_{ B } -y_{ { \rm{ A } } } } \right.  ) ^ { 2 } +\left ( { z_{ B } -z_{ A } } \right.  ) ^ { 2 } } \right.$⑵ Độ dài véctơ $a$:$\left | { a } \right.  |=\sqrt{ \left ( { a_{ 1 } } \right.  ) ^ { 2 } +\left ( { a_{ 2 } } \right.  ) ^ { 2 } +\left ( { a_{ 3 } } \right.  ) ^ { 2 } }$ $\left. \rightarrow \left | { a } \right.  | ^ { 2 } =a ^ { 2 } =\left ( { a_{ 1 } } \right.  ) ^ { 2 } +\left ( { a_{ 2 } } \right.  ) ^ { 2 } +\left ( { a_{ 3 } } \right.  ) ^ { 2 } \right.$ Phương pháp

**Ví dụ 3.1.** Trong không gian $Oxyz$,cho $A\left ( { 1;2;-1 } \right.  )$ và $B\left ( { 0;3;1 } \right.  ).$ Tính độ dài đoạn thẳng $AB.$

*Lời giải:*

Ta có $\overrightarrow { AB }=\left ( { -1;1;2 } \right.  )$ $⇒AB=\sqrt{ \left ( { -1 } \right.  ) ^ { 2 } +1 ^ { 2 } +2 ^ { 2 } }=\sqrt{ 6 }$

**Ví dụ 3.2.** Trong không gian $Oxyz$, cho tam giác $ABC$ biết $A\left ( { 1\,;0\,;\,-2 } \right.  )\,,\,B\left ( { 2\,;\,1\,;\,-1 } \right.  )$,$C\left ( { 1\,;\,-2\,;\,2 } \right.  )$. Tìm chu vi củatam giác $ABC$.

*Lời giải:*

Theo công thức tính độ dài ta được

$AB=\sqrt{ \left ( { 2-1 } \right.  ) ^ { 2 } +\left ( { 1-0 } \right.  ) ^ { 2 } +\left ( { -1+2 } \right.  ) ^ { 2 } }=\sqrt{ 3 }$;

$BC=\sqrt{ 1+9+9 }=\sqrt{ 10 }$;

$AC=\sqrt{ 0+4+16 }=2\sqrt{ 5 }$.

Chu vi của $ABC:$ $\sqrt{ 3 }+\sqrt{ 10 }+2\sqrt{ 5 }$.

**Ví dụ 3.3.** Trong không gian $Oxyz$,cho $A\left ( { 1;2;-1 } \right.  ),\,\,B\left ( { 0;3;1 } \right.  );\,\,C\left ( { 3;2;0 } \right.  ).$ Tính diện tíchtam giác $ABC$(nếu có).

*Lời giải:*

Ta có $\overrightarrow { AB }=\left ( { -1;1;2 } \right.  )$ và $\overrightarrow { AC }=\left ( { 2;0;1 } \right.  )$ không cùng phương nên ba điểm $A;B;C$ lập thành tam giác.

Và $\left. \overrightarrow { AB }.\overrightarrow { AC }=-1.2+1.0+2.1=0 \right.$ $\left. \left. ⇒\overrightarrow { AB }⊥\overrightarrow { AC }⇒AB⊥AC \right. \right.$ nênΔABCvuông tại $A.$

Mặt khác $AB=\sqrt{ \left ( { -1 } \right.  ) ^ { 2 } +1 ^ { 2 } +2 ^ { 2 } }=\sqrt{ 6 }$ và $AC=\sqrt{ 2 ^ { 2 } +0+1 ^ { 2 } }=\sqrt{ 5 }$

Vậy diện tích tam giác $ABC$ là $S=\frac { 1 } { 2 }AB.AC=\frac { 1 } { 2 }\sqrt{ 6 }.\sqrt{ 5 }=\frac { \sqrt{ 30 } } { 2 }.$

**Ví dụ 3.4.** Trong không gian $Oxyz$, cho ba điểm $A\left ( { 2\,;0\,;0 } \right.  ),\,\,B\left ( { 0\,;3\,;1 } \right.  ),\,\,C\left ( { -3\,;6\,;4 } \right.  )$. Tìm điểm $M$ thuộc đoạn $BC$ sao cho $MC=2MB$. Tìm độ dài đoạn $AM$.

Điểm $M∈BC$:$MC=2MB\,\,⇒\,\,\overrightarrow   BM  =\frac   1     3  \overrightarrow   BC  ⇔\,\,$ $⇔\,\,⇒\,\,M\left ( { -1\,;\,4\,;\,2 } \right. )$.

Vậy $AM=\sqrt{ 9+16+4 }=\sqrt{ 29 }$.

### Dạng 4. Sự cùng phương của hai vectơ

Xét hai véctơ $a=\left ( { a_{ 1 } ;a_{ 2 } ;a_{ 3 } } \right.  )$ và $b=\left ( { b_{ 1 } ;b_{ 2 } ;b_{ 3 } } \right.  )$ ta có:⑴ Hai véctơ bằng nhau:$a=b⇔\left\{ \begin{array}{l} a_{ 1 } =b_{ 1 } a_{ 2 } =b_{ 2 } a_{ 3 } =b_{ 3 } \end{array} \right.$⑵ Véctơ $a$ cùng phương véctơ $b$:$a=k.b⇔\left\{ \begin{array}{l} a_{ 1 } =k.b_{ 1 } a_{ 2 } =k.b_{ 2 } a_{ 3 } =k.b_{ 3 } \end{array} \right.$ Phương pháp

**Ví dụ 4.1.** Trong không gian $Oxyz$,cho các vectơ $a=\left ( { 4;1;-2 } \right.  )$;$b=\left ( { 1;-2;-1 } \right.  )$;$c=\left ( { 8;2;-4 } \right.  )$;$d=\left ( { -4;-1;2 } \right.  )$. Vectơ $a=\left ( { 4;1;-2 } \right.  )$ cùng phương với vectơ nào đã cho?

*Lời giải:*

Xét $\left\{ \begin{array}{l} a=\left ( { 4;1;-2 } \right.  )b=\left ( { 1;-2;-1 } \right.  ) \end{array} \right.⇒\frac { 4 } { 1 }≠\frac { 1 } { -2 }≠\frac { -2 } { -1 }$ nên $a$ không cùng phương $b$.

Xét $\left\{ \begin{array}{l} a=\left ( { 4;1;-2 } \right.  )c=\left ( { 8;2;-4 } \right.  ) \end{array} \right.⇒\frac { 4 } { 8 }=\frac { 1 } { 2 }=\frac { -2 } { -4 }$ nên $a$ cùng phương $c$.

Xét $\left\{ \begin{array}{l} a=\left ( { 4;1;-2 } \right.  )d=\left ( { -4;-1;2 } \right.  ) \end{array} \right.⇒\frac { 4 } { -4 }=\frac { 1 } { -1 }=\frac { -2 } { 2 }$ nên $a$ cùng phương $d$.

Vậy vectơ $a$ cùng phương với vectơ $c$ và $d$.

**Ví dụ 4.2.** Trong không gian $Oxyz$,cho hai vectơ $a=\left ( { 1;1;5 } \right.  )$ và $b=\left ( { m+1;2n;10 } \right.  ).$ Tìm $m,\,n$ để hai vectơ $a$ và $b$ cùng phương.

*Lời giải:*

Để hai vectơ $a$ và $b$ cùng phương khi và chỉ khi $\left\{ \begin{array}{l} a_{ 1 } =kb_{ 1 } a_{ 2 } =kb_{ 1 } a_{ 3 } =kb_{ 3 } \end{array} \right.⇔\left\{ \begin{array}{l} 1=k\left ( { m+1 } \right.  )1=k\left ( { 2n } \right.  )5=k.10 \end{array} \right.⇔\left\{ \begin{array}{l} k=\frac { 1 } { 2 }m=1n=1 \end{array} \right.$

Vậy:$m=1;\,\,n=1.$
