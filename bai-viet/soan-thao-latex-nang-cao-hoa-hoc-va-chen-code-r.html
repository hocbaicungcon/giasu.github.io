Soạn thảo LaTeX nâng cao: Gõ công thức Hóa học và chèn mã nguồn R/Python

Hướng dẫn viết phương trình phản ứng, công thức cấu tạo hóa học bằng mhchem, chemfig và cách nhúng mã nguồn R code trong LaTeX với listings và minted.

Sau khi đã nắm vững các kỹ năng cơ bản và cách gõ công thức toán học, rất nhiều bạn đặt câu hỏi: Liệu LaTeX có hỗ trợ tốt cho môn Hóa học không? Và Làm thế nào để nhúng R code in LaTeX hoặc mã nguồn Python để phục vụ báo cáo phân tích dữ liệu, khoa học máy tính?

Bài viết này sẽ hướng dẫn chi tiết cách sử dụng các gói lệnh chuyên dụng để giải quyết trọn vẹn hai bài toán trên.

1. Soạn thảo công thức và phương trình Hóa học trong LaTeX (mhchem)

Để viết các chất hóa học và phương trình phản ứng một cách tự nhiên nhất mà không phải gõ thủ công từng chỉ số trên/dưới, gói lệnh mhchem là giải pháp hàng đầu.

1.1. Khai báo gói lệnh

Trong phần Preamble, bạn chỉ cần thêm:

\usepackage[version=4]{mhchem}

1.2. Cách viết công thức phân tử và ion

Sử dụng lệnh \ce{...} (viết tắt của Chemical Equation):

Chất / Phản ứng Lệnh LaTeX với mhchem Kết quả hiển thị
Phân tử nước \ce{H2O} H2O\text{H}_2\text{O}H2​O
Axit sunfuric \ce{H2SO4} H2SO4\text{H}_2\text{SO}_4H2​SO4​
Ion Sunfat \ce{SO4^2-} SO42−\text{SO}_4^{2-}SO42−​
Hạt nhân nguyên tử \ce{^{238}_{92}U} 92238U^{238}_{92}\text{U}92238​U

1.3. Viết phương trình phản ứng hóa học hoàn chỉnh

Gói lệnh tự động canh chỉnh mũi tên thuận nghịch, điều kiện nhiệt độ hoặc xúc tác:

% Phản ứng nhiệt phân thuốc tím
\ce{2KMnO4 ->[\Delta] K2MnO4 + MnO2 + O2 ^}

% Cân bằng thuận nghịch phản ứng tổng hợp Amoniac
\ce{N2 + 3H2 <=> 2NH3}

2. Vẽ công thức cấu tạo phân tử hữu cơ (chemfig)

Nếu bạn cần vẽ mạch carbon, vòng benzen hay các liên kết đôi/ba trong hóa học hữu cơ, hãy sử dụng gói lệnh chemfig:

\usepackage{chemfig}

% Vẽ phân tử Metan (CH4)
\chemfig{C(-[:90]H)(-[:180]H)(-[:270]H)-H}

% Vẽ vòng Benzen có gắn nhóm -OH (Phenol)
\chemfig{*6(-=-=(-OH)-=)}

chemfig sử dụng cơ chế góc xoay trực quan dựa trên nền tảng TikZ, giúp tạo ra các sơ đồ cấu tạo phân tử sắc nét ở độ phân giải vector cao nhất.

3. Nhúng mã nguồn và chạy R Code in LaTeX

Đối với các nhà khoa học dữ liệu và sinh viên ngành thống kê, việc trình bày code R hoặc kết quả mô hình trực tiếp trong báo cáo LaTeX là nhu cầu rất phổ biến. Có 2 cách chính:

3.1. Cách 1: Sử dụng gói lệnh listings (Đơn giản, không cần phụ thuộc)

Khai báo trong phần Preamble:

\usepackage{listings}
\usepackage{xcolor}

% Cấu hình hiển thị code
\lstset{
    language=R,
    basicstyle=\ttfamily\small,
    keywordstyle=\color{blue},
    commentstyle=\color{green!50!black},
    stringstyle=\color{red},
    numbers=left,
    numberstyle=\tiny,
    stepnumber=1,
    frame=single,
    breaklines=true
}

Sử dụng trong bài viết:

\begin{lstlisting}[caption={Đoạn code phân tích hồi quy tuyến tính trong R}]
# Tải tập dữ liệu iris và thực hiện hồi quy
data(iris)
model <- lm(Sepal.Length ~ Sepal.Width, data = iris)
summary(model)

# Vẽ đồ thị phân tán
plot(iris$Sepal.Width, iris$Sepal.Length, 
     main="Phân tích Sepal Length vs Sepal Width",
     xlab="Sepal Width", ylab="Sepal Length")
abline(model, col="red")
\end{lstlisting}

3.2. Cách 2: Kết hợp R Markdown / Knitr (.Rnw)

Thay vì chèn code tĩnh, bạn có thể dùng Knitr để nhúng code R động: Khi biên dịch tài liệu, mã nguồn R sẽ thực sự được thực thi trong nền, và kết quả tính toán cùng biểu đồ sinh ra sẽ tự động chèn thẳng vào file PDF báo cáo.

5. Câu hỏi trắc nghiệm kiểm tra nhanh

Trong LaTeX, gói lệnh nào phổ biến nhất để viết nhanh các công thức và phương trình hóa học bằng cú pháp \ce{...}?

Giải thích
Gói lệnh mhchem cung cấp lệnh \ce{...} giúp viết phương trình phản ứng, công thức hóa học và ion cực kỳ ngắn gọn và trực quan.
Để định dạng và tô màu cú pháp mã nguồn lập trình (R, Python, C++...) trong tài liệu LaTeX, gói lệnh cơ bản nào thường được sử dụng?

Giải thích
Gói lệnh listings (hoặc minted) được thiết kế riêng để hiển thị mã nguồn các ngôn ngữ lập trình với tính năng đánh số dòng và tô màu cú pháp.
