Bài 18. Phương trình quy về phương trình bậc hai

Nhiều bài toán vật lí, tối ưu hóa đường đi của tàu cứu hộ hay tính toán quỹ đạo trong không gian dẫn đến các phương trình chứa căn thức hoặc phương trình bậc bốn. Bằng các phép biến đổi đại số khéo léo như bình phương hai vế hoặc đặt ẩn phụ, ta có thể quy những bài toán phức tạp này về phương trình bậc hai quen thuộc. Trọng tâm cốt lõi của bài học là kỹ thuật biến đổi tương đương và thử lại để loại bỏ triệt để nghiệm ngoại lai.

1. Sơ đồ tư duy (Mindmap) Phương trình quy về bậc hai

1. Dạng f(x)=g(x)\sqrt{f(x)} = \sqrt{g(x)}f(x)​=g(x)​

• Bước 1: Bình phương hai vế f(x)=g(x)f(x) = g(x)f(x)=g(x).
• Bước 2: Giải tìm nghiệm xxx.
• Bước 3: Thay nghiệm vào kiểm tra (hoặc đặt điều kiện g(x)⩾0g(x) \ge 0g(x)⩾0).

2. Dạng f(x)=g(x)\sqrt{f(x)} = g(x)f(x)​=g(x)

• Điều kiện bắt buộc: g(x)⩾0g(x) \ge 0g(x)⩾0.
• Bình phương hai vế: f(x)=[g(x)]2f(x) = [g(x)]^2f(x)=[g(x)]2.
• Giải phương trình bậc hai và so sánh điều kiện.

3. Phương trình trùng phương

• Dạng ax4+bx2+c=0ax^4 + bx^2 + c = 0ax4+bx2+c=0 (a≠0a \ne 0a=0).
• Đặt t=x2t = x^2t=x2 (t⩾0t \ge 0t⩾0).
• Đưa về at2+bt+c=0at^2 + bt + c = 0at2+bt+c=0, lấy nghiệm t⩾0  ⟹  x=±tt \ge 0 \implies x = \pm\sqrt{t}t⩾0⟹x=±t​.

4. Nghiệm ngoại lai (Extraneous)

• Phép bình phương là phép biến đổi hệ quả (không tương đương).
• Luôn phải có bước thử lại nghiệm trước khi kết luận tập nghiệm SSS.

2. Khởi động: 5 câu hỏi nhanh & Cảnh báo bẫy nghiệm ngoại lai

  1. Phương trình x−3=−2\sqrt{x - 3} = -2x−3​=−2 có nghiệm không?
    Đáp án: Vô nghiệm ngay lập tức, vì căn bậc hai số học không thể nhận giá trị âm.
  2. Nếu bình phương hai vế phương trình x−3=−2\sqrt{x - 3} = -2x−3​=−2, ta được gì?
    Đáp án: x−3=4  ⟹  x=7x - 3 = 4 \implies x = 7x−3=4⟹x=7. Nhưng thay x=7x = 7x=7 vào: 4=2≠−2\sqrt{4} = 2 \ne -24​=2=−2! Số 777 chính là một nghiệm ngoại lai sinh ra do bình phương số âm.
  3. Khi giải f(x)=g(x)\sqrt{f(x)} = \sqrt{g(x)}f(x)​=g(x)​, ta có cần đặt điều kiện cho cả hai biểu thức f(x)⩾0f(x) \ge 0f(x)⩾0 và g(x)⩾0g(x) \ge 0g(x)⩾0 không?
    Đáp án: Không cần cả hai, chỉ cần một trong hai (chọn biểu thức đơn giản hơn) vì khi f(x)=g(x)f(x) = g(x)f(x)=g(x) thì biểu thức này dương sẽ kéo theo biểu thức kia dương.
  4. Phương trình x4−5x2+4=0x^4 - 5x^2 + 4 = 0x4−5x2+4=0 có bao nhiêu nghiệm thực?
    Đáp án: Đặt t=x2⩾0  ⟹  t2−5t+4=0  ⟹  t=1t = x^2 \ge 0 \implies t^2 - 5t + 4 = 0 \implies t = 1t=x2⩾0⟹t2−5t+4=0⟹t=1 hoặc t=4t = 4t=4. Cả hai đều thỏa mãn t>0  ⟹  x=±1,x=±2t > 0 \implies x = \pm 1, x = \pm 2t>0⟹x=±1,x=±2 (tổng cộng 4 nghiệm thực).
  5. Cách giải an toàn và chuẩn mực nhất theo SGK Kết nối tri thức là gì?
    Đáp án: Bình phương hai vế để tìm tất cả các nghiệm tiềm năng, sau đó thay từng nghiệm vào phương trình ban đầu để kết luận.

3. Lý thuyết trọng tâm

Ghi nhớ

  3. Giải phương trình tìm các nghiệm xxx.
  4. Thử lại: Thay các giá trị xxx vừa tìm được vào phương trình ban đầu. Giá trị nào thỏa mãn là nghiệm của phương trình; giá trị nào không thỏa mãn là nghiệm ngoại lai và bị loại bỏ.

4. Widget tương tác: Máy Giải & Kiểm Tra Nghiệm Ngoại Lai

Nhập các hệ số để xem quy trình giải tự động phương trình dạng ax2+bx+c=dx+e\sqrt{ax^2 + bx + c} = dx + eax2+bx+c​=dx+e, kiểm tra điều kiện hai vế và phân loại nghiệm thật / nghiệm ngoại lai:

Giải Phương Trình Căn Thức ax2+bx+c=dx+e\sqrt{ax^2 + bx + c} = dx + eax2+bx+c​=dx+e

Kiểm tra nghiệm ngoại lai
Phương trình: √(2x² - 3x - 5) = x - 1
• Bình phương hai vế: 2x² - 3x - 5 = (x - 1)² = x² - 2x + 1
• Thu gọn: x² - x - 6 = 0
• Nghiệm tiềm năng: x = 3 hoặc x = -2
Kết luận thử lại:
• Thay x = 3: VT = √(2·9 - 9 - 5) = √4 = 2; VP = 3 - 1 = 2 (Thỏa mãn ✅)
• Thay x = -2: VP = -2 - 1 = -3 < 0 (Loại ❌ - Nghiệm ngoại lai)
➔ Tập nghiệm S = {3}

7. Trắc nghiệm kiểm tra hiểu bài (10 câu có chấm điểm & giải thích chi tiết)

Câu 1/10

Nghiệm của phương trình 2x−3=x+2\sqrt{2x - 3} = \sqrt{x + 2}2x−3​=x+2​ là:

Giải thích
Bình phương hai vế: 2x−3=x+2  ⟺  x=52x - 3 = x + 2 \iff x = 52x−3=x+2⟺x=5. Thay x=5x = 5x=5 vào thấy thỏa mãn.

Câu 2/10

Phương trình x2−3x+2=x−1\sqrt{x^2 - 3x + 2} = x - 1x2−3x+2​=x−1 có bao nhiêu nghiệm thực?

Giải thích
Bình phương hai vế: x2−3x+2=(x−1)2=x2−2x+1  ⟺  −x=−1  ⟺  x=1x^2 - 3x + 2 = (x - 1)^2 = x^2 - 2x + 1 \iff -x = -1 \iff x = 1x2−3x+2=(x−1)2=x2−2x+1⟺−x=−1⟺x=1. Thay x=1x = 1x=1 vào: VT = 0, VP = 0 (thỏa mãn). Vậy phương trình có duy nhất 1 nghiệm thực là x=1x = 1x=1.

Câu 3/10

Số nghiệm của phương trình x2−4=x−2\sqrt{x^2 - 4} = x - 2x2−4​=x−2 là:

Giải thích
Bình phương: x2−4=x2−4x+4  ⟺  4x=8  ⟺  x=2x^2 - 4 = x^2 - 4x + 4 \iff 4x = 8 \iff x = 2x2−4=x2−4x+4⟺4x=8⟺x=2. Thử lại x=2x = 2x=2: VT = 0, VP = 0 (Thỏa mãn). Phương trình có 1 nghiệm duy nhất.

Câu 4/10

Phương trình x+1=x−1\sqrt{x + 1} = x - 1x+1​=x−1 có nghiệm là:

Giải thích
Bình phương: x+1=x2−2x+1  ⟺  x2−3x=0  ⟺  x=0x + 1 = x^2 - 2x + 1 \iff x^2 - 3x = 0 \iff x = 0x+1=x2−2x+1⟺x2−3x=0⟺x=0 hoặc x=3x = 3x=3. Thử lại: x=0  ⟹  x = 0 \impliesx=0⟹ VP = -1 < 0 (Loại). x=3  ⟹  x = 3 \impliesx=3⟹ VT = 2, VP = 2 (Nhận). Nghiệm duy nhất x=3x = 3x=3.

Câu 5/10

Phương trình x4−10x2+9=0x^4 - 10x^2 + 9 = 0x4−10x2+9=0 có tất cả bao nhiêu nghiệm thực?

Giải thích
Đặt t=x2⩾0  ⟹  t2−10t+9=0  ⟺  t=1t = x^2 \ge 0 \implies t^2 - 10t + 9 = 0 \iff t = 1t=x2⩾0⟹t2−10t+9=0⟺t=1 hoặc t=9t = 9t=9. Do đó x=±1x = \pm 1x=±1 và x=±3x = \pm 3x=±3 (tổng cộng 4 nghiệm thực).

Câu 6/10

Phương trình 3x2−9x+1=x−2\sqrt{3x^2 - 9x + 1} = x - 23x2−9x+1​=x−2 có bao nhiêu nghiệm thực?

Giải thích
Bình phương: 3x2−9x+1=x2−4x+4  ⟺  2x2−5x−3=0  ⟺  x=33x^2 - 9x + 1 = x^2 - 4x + 4 \iff 2x^2 - 5x - 3 = 0 \iff x = 33x2−9x+1=x2−4x+4⟺2x2−5x−3=0⟺x=3 hoặc x=−1/2x = -1/2x=−1/2. Thử lại: với x=−1/2x = -1/2x=−1/2, VP = −2,5<0-2,5 < 0−2,5<0 (Loại). Với x=3x = 3x=3, VT = 27−27+1=1\sqrt{27 - 27 + 1} = 127−27+1​=1, VP = 3−2=13 - 2 = 13−2=1 (Nhận). Vậy phương trình có 1 nghiệm.

Câu 7/10

Tổng các nghiệm của phương trình x2−2x−3=x+1\sqrt{x^2 - 2x - 3} = \sqrt{x + 1}x2−2x−3​=x+1​ bằng:

Giải thích
Bình phương: x2−2x−3=x+1  ⟺  x2−3x−4=0  ⟺  x=−1x^2 - 2x - 3 = x + 1 \iff x^2 - 3x - 4 = 0 \iff x = -1x2−2x−3=x+1⟺x2−3x−4=0⟺x=−1 hoặc x=4x = 4x=4. Thử lại: cả hai đều thỏa mãn. Tổng các nghiệm: (−1)+4=3(-1) + 4 = 3(−1)+4=3.

Câu 8/10

Tập nghiệm của phương trình x4+3x2−4=0x^4 + 3x^2 - 4 = 0x4+3x2−4=0 là:

Giải thích
Đặt t=x2⩾0  ⟹  t2+3t−4=0  ⟺  t=1t = x^2 \ge 0 \implies t^2 + 3t - 4 = 0 \iff t = 1t=x2⩾0⟹t2+3t−4=0⟺t=1 (nhận) hoặc t=−4t = -4t=−4 (loại vì âm). x2=1  ⟹  x=±1x^2 = 1 \implies x = \pm 1x2=1⟹x=±1.

Khi giải phương trình f(x)=g(x)\sqrt{f(x)} = g(x)f(x)​=g(x), tại sao ta có thể nhận phải nghiệm ngoại lai?

Câu 10/10

Tích các nghiệm của phương trình x2−3x+2=2x−4\sqrt{x^2 - 3x + 2} = \sqrt{2x - 4}x2−3x+2​=2x−4​ là:
