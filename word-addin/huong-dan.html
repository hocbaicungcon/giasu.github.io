Cài add-in “TexCraft Công thức” cho Word

Add-in giúp quét/chuyển công thức MathType sang công thức Word, tìm–thay LaTeX, chuẩn hóa/trộn đề và xuất đáp án Excel. Tác giả: thầy Phan Văn Phương (THPT Xuân Trường B).

Lưu ý: add-in còn là bản thử nghiệm. Hãy thử trên một bản sao của tài liệu trước, đừng dùng trực tiếp trên file gốc quan trọng.

Bước 1. Tải file manifest

Tải manifest.xml (nếu trình duyệt mở ra thành chữ, nhấn chuột phải → Lưu liên kết thành…). Mọi máy dùng chung một file này.

Mac

  1. Mở Finder → Go → Go to Folder, dán đường dẫn:
    ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/
    (nếu chưa có thư mục wef thì tạo mới).
  2. Chép manifest.xml vào đó.
  3. Thoát hẳn Word (Cmd+Q) rồi mở lại.
  4. Vào Chèn → Add-ins → My Add-ins → Developer Add-ins → TexCraft Công thức.

Windows

  1. Tạo một thư mục (vd. C:\WordAddins), chép manifest.xml vào, chia sẻ thư mục (chuột phải → Properties → Sharing) để có đường dẫn dạng \\TÊN-MÁY\WordAddins.
  2. Trong Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs; dán đường dẫn vào ô Catalog URL → Add catalog, tích Show in Menu → OK. Thoát hẳn Word rồi mở lại.
  3. Chèn → Add-ins → My Add-ins → Shared Folder → chọn TexCraft Công thức → Add.

Word trên web

Mở tài liệu trên Word web → Chèn → Add-ins → My Add-ins → Upload My Add-in → chọn manifest.xml.

Cập nhật

Khi tác giả cập nhật add-in trên website, các máy không phải cài lại. Nếu Word còn nhớ bản cũ: thoát hẳn Word rồi mở lại.
