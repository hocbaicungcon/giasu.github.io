Cài “TexCraft Công thức” cho Word

Chỉ cần 1 file và 3 bước. Cài một lần, dùng mãi; add-in tự cập nhật.

① Tải file manifest.xml

Máy Mac

  1. Mở Finder → nhấn phím tắt Cmd + Shift + G (Đi tới thư mục…), dán: ~/Library/Containers/com.microsoft.Word/Data/Documents/wef rồi bấm Enter.
    (Lưu ý: Nếu Finder báo không tìm thấy, hãy dán ~/Library/Containers/com.microsoft.Word/Data/Documents rồi tạo một thư mục mới đặt tên là wef).
  2. Kéo file manifest.xml (vừa tải ở trên) vào thư mục wef đó (chọn Thay thế / Replace nếu đã có file cũ).
  3. Thoát hẳn Word (Cmd + Q), sau đó mở lại Word và mở một tài liệu mới:
    • Vào tab Trang đầu (Home) hoặc Chèn (Insert).
    • Ở góc phải thanh công cụ, bấm vào nút Add-ins (hoặc Tiện ích bổ sung, hoặc mũi tên xổ xuống ⌄ ngay cạnh nút).
    • Tìm mục Developer Add-ins (hoặc Tiện ích bổ sung cho nhà phát triển).
    • Bấm chọn TexCraft Công thức (hoặc nút Add).
    Ngay lập tức bảng TexCraft sẽ mở ra ở cạnh phải màn hình Word và tab Trang đầu (Home) sẽ có thêm nút bấm riêng của TexCraft để dùng thuận tiện.

Máy Windows

  1. Tạo thư mục, ví dụ C:\WordAddins, chép manifest.xml vào, chuột phải thư mục → Give access to → Specific people → Share, để lấy đường dẫn dạng \\TÊN-MÁY\WordAddins.
  2. Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs, dán đường dẫn vào Catalog URL → Add catalog, tích Show in Menu → OK, rồi thoát hẳn Word.
  3. Mở Word → Chèn → Add-ins → My Add-ins → Shared Folder → TexCraft Công thức → Add.

Word trên web (dễ nhất, không cần chép file)

Mở tài liệu trên Word web → Chèn → Add-ins → My Add-ins → Upload My Add-in → chọn manifest.xml.

Add-in còn là bản thử nghiệm: hãy thử trên bản sao của tài liệu trước. Tác giả: thầy Phan Văn Phương, THPT Xuân Trường B.
