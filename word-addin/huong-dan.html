Cài đặt “TexCraft Công thức & Đề thi” cho Microsoft Word

Tiện ích hỗ trợ đọc, chuyển và sửa hàng loạt công thức MathType, LaTeX sang công thức Word chuẩn; phân tích, chuẩn hóa và trộn đề thi trắc nghiệm.

Đã cài xong? Xem hướng dẫn sử dụng chi tiết có hình minh họa.

Chỉ cần 1 file và 3 bước đơn giản. Cài đặt một lần, dùng lâu dài; add-in tự động cập nhật tính năng mới.

Tải file manifest.xml

1. Cài đặt trên máy Mac (macOS)

  1. Mở Finder → nhấn tổ hợp phím Cmd + Shift + G (Đi tới thư mục…), dán đường dẫn sau rồi nhấn Enter:
    ~/Library/Containers/com.microsoft.Word/Data/Documents/wef
    (Lưu ý: Nếu Finder báo không tìm thấy, hãy dán ~/Library/Containers/com.microsoft.Word/Data/Documents rồi tạo một thư mục mới đặt tên là wef).
  2. Kéo file manifest.xml (vừa tải ở trên) vào thư mục wef (chọn Thay thế / Replace nếu đã có file cũ).
  3. Thoát hẳn Microsoft Word (Cmd + Q), sau đó mở lại Word và mở một tài liệu mới:
    • Trên thanh menu Ribbon, tab riêng TexCraft sẽ xuất hiện (hoặc vào tab Trang đầu / Home → bấm nút Add-ins / Tiện ích bổ sung → tìm mục Developer Add-ins).
    • Bấm chọn tiện ích để mở bảng điều khiển TexCraft.

2. Cài đặt trên máy Windows

  1. Tạo một thư mục trên ổ đĩa, ví dụ: C:\WordAddins, chép file manifest.xml vào thư mục này.
  2. Chuột phải vào thư mục đó → chọn Properties → tab Sharing → bấm nút Share… → chọn người dùng hoặc Everyone → bấm Share để lấy đường dẫn mạng chia sẻ dạng: \\TÊN-MÁY\WordAddins.
  3. Mở Microsoft Word → vào menu File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs:
    • Dán đường dẫn vừa sao chép vào ô Catalog URL.
    • Bấm Add catalog và tích chọn ô Show in Menu → bấm OK.
  4. Thoát hẳn Word rồi mở lại → vào Insert (Chèn) → Add-ins → My Add-ins → Shared Folder (Thư mục dùng chung) → TexCraft Công thức → Add.

3. Sử dụng trên Word Online (Trình duyệt Web)

Mở bất kỳ tài liệu nào trên Word Web (Office.com) → vào tab Chèn (Insert) → Add-ins → My Add-ins → Upload My Add-in (Tải lên tiện ích của tôi) → chọn file manifest.xml vừa tải về.

Khuyến nghị: Khi thực hiện chuyển đổi công thức hoặc trộn đề số lượng lớn, thầy cô nên thao tác trên bản sao của tài liệu để an toàn tuyệt đối. Tác giả: thầy Phan Văn Phương, giáo viên THPT Xuân Trường B, Nam Định.
